一、任务及执行范围

在当前实际仓库中实现 Av2：保留普通 A/B 学习与指定客户端聚合，在 ordinary A 之后，用与历史参考绑定的来源结构生成有限修正，通过头、中、尾三组训练损失与自身目标验收后提交。

实施时先检查仓库并实现最小单元，完成必要的小测试和一次六轮 GPU smoke，最后提供四条正式实验的真实启动命令。不要默认启动完整训练矩阵。本文没有授权当前对话实际修改仓库或运行 GPU。

不增加方法 B/共享 C、QP、对偶变量、组惩罚搜索、动态开放日程或新的来源映射。不扩展候选比例，不做容差搜索，不根据测试准确率调整算法或追加训练。

不建设额外精度审计系统：不强制模型及全部损失改用 FP64；不逐轮重复同状态前向；不每轮同时运行慢速与缓存反馈；不每个候选计算全量指纹；不默认保存完整梯度及逐步来源矩阵。既有聚合求解器的 FP64 和算法保持不变。

三、固定实验矩阵

本轮计划新增恰好四条完整轨迹，均为 seed42：
R1：TailRW16 + Av2
R2：joint + Av2
R3：joint_floor16 + Av2
R4：joint_floor16 + ordinary A（关闭历史修正及 Av2 来源反馈）

同聚合 ordinary A 是首要配对基线。TailRW16 + ordinary A 与 joint + ordinary A 使用此前条件匹配的结果。训练不依赖对照目录；目录缺失时仍可训练并完成自身汇总，缺失比较标注 unavailable，不自动补跑。

不默认新增 FedAvg + Av2，不自动重跑全部旧 Full-CP，不追加种子或参数网格。已有匹配旧 A 结果可以事后纳入；历史 A+C 不作为 A 单独对照。

三行两列配对设计可以分别比较聚合和 Av2；不得用 joint+ordinary 与 floor+Av2 的跨行跨列差值归因单一组件。joint_floor16 的采用继续由 ordinary A 对照决定，不使用 Av2 组合结果事后重写聚合门槛。

- 100 轮；每轮 B 本地学习 3 epoch。
- 第 1—90 轮，在 B 聚合后固定 B，A 本地学习 1 epoch，A 学习率 0.001，其他优化设置沿用原配置。

数据计数由真实输入动态推导。用户报告的预期值为：

固定见证图=5842；两视图=11684；

五、三种聚合

普通 B 和普通 A 均使用该实验登记的同一组固定权重 w，按客户端 ID 对齐，之后 Av2 不重新求权重。

TailRW16：
w_j=(n_j+16*n_j_tail)/(N+16*N_tail)。

joint：
q_j=n_j/N，R_jc=n_jc/n_j，u_c=1/C；
最小化 KL(u || R^T w) + (0.1/2)*sum_j (w_j-q_j)^2/q_j；
沿用现有求解器、可行域和审计。

joint_floor16：
目标与 joint 相同，只将下界改为 w_j >= gamma*q_j；
gamma=N/(N+16*N_tail)。
预期计数对应 gamma=10847/13295=0.81587062805566。
从真实训练计数计算并记录 gamma，不根据模型精度调整；重新优化 w，不能简单混合旧 joint 权重。
如果尚未实现，按这个既定聚合设计接入，保留原 joint 行为；更新下界对应的既有最优性检查，不新建泛化审计框架。

六、见证、模型状态及反馈

q=(k,c) 表示持有见证图的客户端—类别单元；j 表示来源客户端。每个非空 q 沿用最多 8 张固定训练见证图 W_q，两视图为原图和固定水平翻转。不换样，不使用测试样本。

用稳定 sample_id 映射到 owner_client_id、class_id、token_id。身份与配置只在初始化和恢复时检查，不按并发完成顺序排列。

m_iv = s_y(x_iv) - max_{c!=y} s_c(x_iv)，s 为未缩放余弦分数。
来源单元功能 F_qv 是 q 内全部固定见证图 m_iv 的平均，不受历史 valid 掩码影响。

一次反馈逻辑至少能提供：
sample_margins[M,2]；
原有 QR 坐标形式的 token source feedback；
token_gradient_norms[Q,2]（完整 A 参数空间的单元平均功能梯度范数）；
group_ce[3]。
不要保存逐样本完整梯度，不新增逐样本×来源客户端的梯度计算。

正式缓存路径也必须执行逐样本 hinge：先算每张图的缺口，再加权汇总，不能先平均间隔。

反馈在固定模式、固定视图、统一精度下运行。固定见证 loader 使用独立 generator 或确定性顺序；候选反馈不能推进普通训练的数据采样、增强或 dropout 随机序列。沿用项目已有实现，开发阶段确认一次即可。

缓存用轻量模型版本区分 post_b、ordinary、候选和 submitted，不必每阶段做完整参数指纹。所有客户端反馈必须对应同一个指定共享参数状态。

七、来源计算与历史状态

每轮第 1—90 轮，共同起点为 theta_pre=(A_t,Bbar_t)。
在这个状态计算：
g_qv=grad_A F_qv(theta_pre)。
固定 B，本地训练 A 得到各客户端 delta_A_j；未截断 QR 仅用于高效计算响应，不限制最终修正子空间。

对每个 q,j：
raw_qj = min_v <g_qv, delta_A_j>；
a_qj = w_j * raw_qj if raw_qj > 1e-6 else 0。

只在 raw 响应处使用一次 1e-6。乘权重后不能再用 1e-6 筛总量。
同轮来源先暂存，最终提交时累计一次。即使没有历史缺口，也要为后续窗口收集来源。
若所有本地 A 提案均为零，可以直接记录零来源，不必做无意义 QR。

五轮窗口为 1—5、6—10……86—90。
S_qj = sum_{t in window} a_qj,t。
窗口结束时，S_q=sum_j S_qj：
- S_q>0：pi_qj=S_qj/S_q，kappa_q=sum_j pi_qj^2。
- S_q=0：来源未知，reason=no_positive_support。
不能先逐轮归一化 pi 再取平均。真实数值出现 NaN/Inf 明确报错，不转换成“无正源”。

每张样本的历史最少包含：
H、valid；
source_known、source_reason；
绑定的 pi、kappa（未知时为空）；
formation_start/end；
registered_round。
这些字段记录当前历史参考的稳定登记窗口，不声称是真实因果来源。

初始化：
两视图间隔都严格大于 0 才登记，H=min_v m_i,v；
source_known=False，reason=pretrained_unknown，pi/kappa 为空；
registered_round=0，formation_start/end 为空。
其余样本 valid=False，不把无效占位值代入损失。

每个五轮窗口只观察实际 submitted 模型：
h_i=min_{窗口五轮,两视图} m_i,v。
当 h_i>0 且（旧历史无效或 h_i>H_i）时，更新 H。
删除旧 +0.001 提升要求，不另外增加经验改善阈值。
H 更新时，连同来源状态、pi/kappa、窗口和登记轮次整体换版。
新窗口无正源时清除旧来源；H 不更新时不更新绑定来源。
同一 q 内不同样本可绑定不同窗口；保存 pi 快照，不能引用之后会清零的窗口累加器。
窗口结束后，无论有没有 H 更新，都重置本窗口累加器。
第 5 轮提交后登记的状态，第 6 轮才能使用。
第 91—100 轮冻结算法历史库，但继续正常性能和既有样本诊断。

最终历史观察覆盖全部固定见证图；不能只观察已登记样本，否则不能发现新历史。

八、ordinary A 与固定目标

ordinary A：
A_ord=A_t+sum_j w_j*delta_A_j。
这是已完成本轮普通学习的提案，所有修正以其为基准。

全部 A 模块按固定顺序合成联合向量，定义：
R_t=sqrt((1/K_clients)*sum_j ||delta_A_j||_2^2)。
R_t 是一个未加权全局标量。不能用聚合更新范数替代，不能逐模块分别定义球。
即使 sum_j w_j*delta_A_j=0，只要 R_t>0，也不能因此跳过修正。

在 A_ord 上取 m_ord。先选择 valid 历史样本，再构造有限的 k_eff：
- source_known=True：k_eff=绑定的 kappa。
- source_known=False：k_eff=1，仅用于目标计算，不把来源状态改成单源。

T_iv = H_i - (1-k_eff_i)*max(H_i-m_ord_iv,0)。

sigma_qv=max(1e-3,R_t*||g_qv||_2)。
范数来自 post_b 的完整单元平均梯度，不能用 QR 投影范数替代。
sigma 是共享的单元尺度，不解释为逐样本敏感度。

H、k_eff、m_ord、T、sigma、样本权重、R_t、A_ord 在本次修正中固定并停止梯度。

九、历史权重、损失与三组 CE

设 K_kc=固定见证总数，b_i=n_kc/K_kc。
令 H_c 为当前类别 c 的 valid 历史样本，C_hist 为至少含一个 valid 历史的类别集合。
omega_i=(1/|C_hist|)*b_i/sum_{l in H_c} b_l。
无有效历史时 L_hist=0，跳过修正反向，不执行空归一化。
omega 不再乘来源集中度、聚合权重或客户端权重。

L_hist(A)=sum_{i valid} omega_i/4 *
              sum_{v=1,2} [max(T_iv-m_iv(A),0)/sigma_q(i),v]^2。

每次修正反向覆盖全部 valid 历史，而不只覆盖 ordinary 时有缺口的样本。
客户端返回含全局 omega 的本地损失/梯度之和；服务器求和，不重复做视图、样本或客户端平均。
导数检查式：
dL/dm_iv= -omega_i/(2*sigma_qv^2)*max(T_iv-m_iv,0)。

三组 G=Head20、Middle60、Tail20 由固定训练计数决定。
C_g(A)= (1/|classes_g|) * sum_{c in classes_g}
        sum_{k:n_kc>0} (n_kc/n_c)
        * (1/(2*K_kc)) * sum_{i in W_kc,v} CE_i,v(A)。

CE logits = exp(logit_scale)*cosine_scores + 原有 LA 偏置。
沿用原 logit scale 和 LA 实际定义，不移除分类 CE 的尺度。
C_g 使用全部固定见证图，不受 valid 历史掩码影响，不乘聚合权重。

C_pre_g=C_g(A_t,Bbar_t)；
C_ord_g=C_g(A_ord,Bbar_t)；
U_g=C_ord_g+0.1*max(C_pre_g-C_ord_g,0)。

旧整体 R_cls/CP 不进入 Av2；不新增三组软惩罚或对偶变量。三组限制只用于候选提交。

十、三步候选生成与提交

A(z)=A_ord+R_t*z，||z||_2<=1；
J(z)=0.5*||z||_2^2+10*L_hist(A(z))。

z0=0，eta=0.1，恰好三步：
z_next=project_global_unit_ball(
    z - 0.1*(z + 10*R_t*grad_A L_hist(A_ord+R_t*z))
)。

反馈接口若返回 grad_A L，就乘一次 R_t；
若已经直接对 z 自动微分，链式法则已含 R_t，不能再乘。

三次梯度分别在 z0、z1、z2 计算，最终得到 z3。不能把第三次反馈当成 z3 的反馈。

候选顺序固定 beta=1、0.5：
A_beta=A_ord+beta*R_t*z3；
在真实 A_beta 上前向，计算 C_beta 与 L_beta；
J_beta=0.5*beta^2*||z3||^2+10*L_beta；
J0=10*L_hist(A_ord)。

接受第一个同时满足以下条件的候选：
三组 C_beta_g <= U_g；
J_beta <= J0。
数值比较统一使用内部 helper；沿用已有合适的小容差。若项目没有 helper，本版只定义一次 leq(x,y): x <= y + 1e-7*max(1,abs(y))，用于这两个比较，不暴露成可搜索参数。
不将这个 helper 用于源阈值、历史严格提高或样本正确性判定。

全幅只通过某一项仍要检查半幅。
半幅从保存的 A_ord 构造，不重算 R、T、sigma、omega。
两者均不通过时精确保留 A_ord，不撤销普通 A 训练。
不增加 0.25、0.125 候选或动态重试。

无 valid 历史、L_hist(A_ord)=0 或 R_t=0 时可直接提交 A_ord，仍执行必要来源统计和最终历史观察。
实际 NaN/Inf 报错，不静默算作普通零修正。
“选择了 beta=1”与“实际参数有非零修正”分开记录。

三组比较是训练见证损失约束，不是测试准确率保证。
这是三步生成候选加有限候选验收，不声称求得非凸约束最优解。

十一、每轮主流程伪代码

for t in 1..100:
    按原路径固定 A，本地学习 B 并用本组 w 聚合
    保存 post_b 共享状态

    if t <= 90:
        在共同 post_b 状态取得全部 q 来源梯度反馈及 C_pre
        按原路径固定 B，本地学习 A
        按 client_id 对齐 delta_A_j
        计算本轮来源 a_qj（暂存，不推进窗口）
        聚合得到 A_ord
        取得 ordinary 的全部见证间隔、C_ord
        从本轮开始前的历史构建固定目标、权重、尺度

        若自然跳过条件成立:
            accepted = ordinary
        否则:
            生成 z3
            检查 full：真实前向，三组 CE 和 J 联合验收
            未通过再检查 half
            均未通过则 accepted = ordinary

        提交 accepted
        复用 accepted 的对应反馈，或补齐缺失的全部见证间隔
        仅在本次提交时累计一次 a_qj 和样本窗口间隔
        窗口结束时按规则登记历史，下轮生效
    else:
        提交 post_b
        冻结 Av2 算法历史

    按原统一测试口径记录正式提交模型性能
    按现有节奏保存与提交模型对应的完整 checkpoint

十二、checkpoint 与最小日志

沿用项目常规 checkpoint 节奏，将最终模型、历史、未完成窗口、来源累加器、last_committed_round 及必要训练/RNG状态保存在同一个完整状态中。临时文件写完再替换即可，不建设通用事务恢复系统。

恢复时检查 schema、配置和固定样本身份，旧 token 历史不能直接伪装成 Av2 样本历史。重复提交不能累计两次。

复用已有性能与预测文件，不改变旧路径格式。Av2 可新增一个简洁的逐轮 CSV，包含：
round、aggregation_rule、variant；
valid_history_count；
known/pretrained_unknown/no_positive_support 数量（H/M/T 可用固定列）；
had_history_deficit、candidate_attempted、selected_beta、nonzero_correction；
full/half 的拒绝原因（H/M/T/J，可多项）；
J0、J_final；
source_seconds、repair_seconds、candidate_check_seconds。

既有预算文件继续记录普通 A/B 步数、实际总耗时及原有通信口径。
不默认保存每步完整梯度、全部候选逐图预测或大量来源矩阵。
sigma 下限比例、每步 J 和球投影情况仅作为按需 debug 统计。

所有运行写独立输出目录，不覆盖旧结果。训练不读取旧实验准确率来控制更新。

十三、最小验证

1. 小型数学/状态测试：
- 不均匀 omega、双视图及 R!=1，检查梯度无重复平均或重复乘 R。
- 同一 q 内有正确/错误图，逐图 hinge 不被平均掩盖。
- 初始化未知、窗口首次登记、H 不提高不换来源、H 提高但无源清除旧来源。
- 第 5 轮登记，第 6 轮使用；同单元不同图绑定不同不可变来源快照。
- raw>1e-6 且权重约 1e-12 仍为合法正支持，归一化无二次阈值。
- full CE 通过但 J 失败时继续 half；half 的 beta^2 正则正确；zero 精确保留 ordinary。
- 断点窗口状态及稳定 sample_id 对齐。
