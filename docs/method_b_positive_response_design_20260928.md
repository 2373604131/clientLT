# 方法 B 修正主方案：目标尾类的正响应蒸馏

日期：2026-09-28。状态：方法设计稿，尚未实现或验证。

2026-09-29 状态更新：结合旧共享 B 的正收益，当前优先保留 C，研究如何改进来源关系和反馈使用。本稿第6节“取消 C、直接训练 B”已降为备选，不代表已经固定的下一版实现；正响应监督也可用于优化由 C 生成的共享候选。见[旧版 B 与故事主线审查](旧版B与故事主线一致性审查_20260929.md)。

实现更新：已按后续确认的“保留独立 donor C＋正响应监督”完成首版代码，实际算法、两组实验与启动命令见[实现及实验说明](cliplora_b_response.md)。本文保留为历史设计讨论，其中直接优化 B 与更新范数约束未用于本次实现。

本方案接续[长尾迁移调研](../presentation/b_transfer_literature_20260928/report.md)。此前报告中的非负组合与交叉影响约束可作为工程对照；本次将主方案推进到迁移内容的改变：从 donor 参数更新中测量目标端的有益功能响应，再用这些响应监督同一个共享模型。

## 1. 固定目标与核心假设

**功能保持能够改善已有尾类能力的维护，但直接监督来源仍然有限。进一步分析表明，缺少目标尾类标签的客户端也能提供正向帮助，因此我们通过 B 的定向知识迁移，增强尾类能够获得的有效学习支持。**

本方案提出的假设是：一个缺少目标标签的 donor 不必成为该类别的完整教师；它对当前共享模型产生的局部正向判别响应，也可能成为有价值的辅助监督。

现有 B 的来源关系已经保留到 U_c 中，但所有 U_c C_c 最终作用于同一个共享模型。单独 donor 的正响应，经过自由矩阵变换与多来源叠加后不一定保留。最新实验没有显示持续 Tail20 增益，但这尚不能唯一归因于 C。新方案把“正响应本身是否可学习、可泛化”作为核心可检验问题。

## 2. 从文献借鉴哪些经验

| 文献经验 | 在本方案中的使用方式 |
|---|---|
| FSA/GistNet 明确区分可共享内容与类别身份 | 不把整个 donor 更新作为最终迁移内容，改为提取目标类别上的响应 |
| MetaSAug/Selective-FD 重视接收端反馈与知识质量 | 以目标端实际响应决定该 donor 对该类的资格与监督权重 |
| DiVE/DKD 说明预测关系可成为监督载体 | 学习目标类与竞争类别之间的相对得分关系 |
| 长尾多目标优化揭示平均收益掩盖类别取舍 | 对每个目标尾类分别构造目标，并在同一个学生上按类等权训练 |

这些是设计原则的适配，不是已经证明能在当前联邦设置中生效的结论。功能响应裁剪也不是严格的语义解耦。

## 3. 迁移单位与数据范围

迁移单位定义为：**某个 donor 在某个目标类样本上，对某个竞争类别产生的正向判别增量。**

- 目标端仍为协议尾部客户端27、28、29中的尾类训练数据，共119张、20类。
- donor 仍必须在目标组之外，且其实际本地数据没有正在帮助的类别 c。
- donor 可以具有其他尾类，也可以在共享模型和 CLIP 预训练知识的基础上作出响应；不能写成该模型从未接触过类别 c。
- 对比保留完整100类。监督图片均为目标尾类图片，但其竞争类别可属于头、中或尾类。
- A 在整个 B 迁移事件中固定；推理时使用一个共享模型，不依赖真实类别选择教师或分支。

## 4. 第一步：在共同基准上识别正向来源

普通本地 B 训练与 FedAvg 后，记共享参数为 B_0。对 donor j，仍用当前协议的原始更新构造探测模型：

\[
B_j^{\mathrm{probe}}=B_0+\eta_p\Delta B_j.
\]

所有 donor 都从同一个 B_0 出发；A、文本特征和 logit scale 固定。这里的增量是一次受控模型扰动的效果，不等于训练数据因果归因。

为使选源更贴近实际判别，定义原始 logits 的正确类—最强竞争类间隔：

\[
h(x,c;B)=z_c(x;B)-\max_{q\ne c}z_q(x;B).
\]

初版使用原图与确定性水平翻转两个视图。先对每个视图在全体目标端 c 类样本上求平均间隔增益，再取较小值：

\[
g_{cj}=\min_{v\in\{0,1\}}
\frac1{N_c}\sum_{x\in D_c}
\big[h(vx,c;B_j^{\mathrm{probe}})-h(vx,c;B_0)\big].
\]

保留 g_cj 为正且满足缺标签规则的 Top-3，记来源集合为 J_c，并将得分归一化为 p_cj。D_c 仅表示目标类的训练样本集合。LA 继续作为分类训练损失和日志指标，但选源不再只依赖平均 LA 下降。正的间隔增益不要求该 donor 已把所有目标样本判对，它也可以改善仍然错误的判别。

两个视图用于降低对单一视图的依赖，不是独立验证集。原先每类都能找到3个 donor 的统计，不保证在这个新判据下仍成立；无合格来源的类别不补入负响应 donor。

## 5. 第二步：按目标类提取需要迁移的正响应

对目标样本 x、真实类 c、竞争类 q，定义相对得分：

\[
m_{cq}(vx;B)=z_c(vx;B)-z_q(vx;B).
\]

先将该类选定 donor 的增量按固定权重合成，再保留在两个视图中均为正的部分：

\[
\bar r_{cq}^{(v)}(x)=\sum_{j\in J_c}p_{cj}
\big[m_{cq}(vx;B_j^{\mathrm{probe}})-m_{cq}(vx;B_0)\big],
\qquad
r_{cq}(x)=\big[\min_v\bar r_{cq}^{(v)}(x)\big]_+.
\]

顺序是“固定来源组合→跨视图一致性→正部截取”。初版不为每个竞争类别临时挑最大 donor，避免把大量噪声赢家拼成过度乐观的教师。

针对每个视图构造学习目标：

\[
m^*_{cq}(vx)=m_{cq}(vx;B_0)+r_{cq}(x).
\]

没有外部改善证据的关系取 r=0，保留当前模型作为参考。它不要求新模型停止提高这些关系；后续采用单侧目标，超过目标不会受到惩罚。

例如，一个 donor 在豹的图片上提高“豹相对猫”的得分差，但在猫的图片上降低“猫相对豹”的得分差。前一条可以成为豹的教学内容，后一条不会作为猫的正向教学内容。猫仍由自己的来源和基准响应定义目标。

这个例子表达的是输出关系的选择，不是在宣称识别出了“毛皮”之类的语义成分。不同输入上的正响应目标也未必能被有限容量的共享 LoRA 同时准确拟合。

## 6. 第三步：用正响应监督共享 B

学生从 B_0 出发，只学习共享 LoRA-B 的增量 ΔB：

\[
B_S=B_0+\Delta B,\qquad\Delta B_{\mathrm{init}}=0.
\]

本方案不再用自由 C 把 donor 参数直接合成最终残差。donor 决定的是各目标类的监督内容；ΔB 是学生对这些内容的共同拟合结果。

竞争类别权重用基准模型在非真实类别上的归一化概率，固定并停止梯度：

\[
\omega^0_{cq}(vx)=\frac{\exp z_q(vx;B_0)}{\sum_{k\ne c}\exp z_k(vx;B_0)}.
\]

这样更容易混淆的类别获得较高权重，同时保留全部竞争类别，不增加 Top-K 竞争类超参数。

定义类等权的响应目标：

\[
\mathcal L_{\mathrm{resp}}=
\frac1{|T|}\sum_{c\in T}\frac1{2N_c}
\sum_{x\in D_c}\sum_v\sum_{q\ne c}\omega^0_{cq}(vx)
\big[m^*_{cq}(vx)-m_{cq}(vx;B_S)\big]_+^2.
\]

它同时表达两种要求：有外部正响应的关系要争取学到增量；其他目标尾类关系提供当前水平的软参考。后者是本次迁移内部的约束，不负责 A 所处理的历史知识维护。

训练目标为

\[
\min_{\Delta B}\quad\mathcal L_{\mathrm{LA,tail}}(B_0+\Delta B)
 +\lambda_{\mathrm{resp}}\mathcal L_{\mathrm{resp}},
\qquad \|\Delta B\|_{\mathrm{effective}}\le R_t.
\]

LA 按全体目标端的“类内样本平均→类别等权”汇总，同样对两视图平均。真实标签负责分类，响应目标提供来源相关的辅助监督。R_t 用固定规则从当轮普通 B 更新范数确定，约束实际有效 LoRA 权重变化，而不是约束分类精度。

教师、p、r、基准与竞争权重全部停止梯度。每个目标客户端计算自己的损失与梯度贡献；服务器按全局类计数合并，再更新同一版学生 B。保留原来的迁移事件时点，先使用相同额外优化步数作可比实现。优化对象已从 C 改为 B，不能直接沿用 C 的学习率0.3。

若整次事件都没有正响应，跳过这次迁移；不把它悄悄退化为额外尾类微调。若仅部分类别无来源，它们仍以 r=0 参与目标池的联合学习。

λ、R_t 的比例、B 学习率需在实现时固定开发配置。这里确定了算法和接口，不把未经验证的数值写成最终超参数，也不按测试精度挑选迁移步。

## 7. 筛选结果怎样直接决定教学内容

对于类别 c 的样本，m* 仅使用 J_c 与 p_cj 构造。对类别 d 的样本，使用另一组 J_d。即使两者的 donor 并集很大，优化器也不能重新把未被 c 认可的 donor 放入 c 的教学目标。

早期版本曾把筛选结果取并集后供共享 C 使用；最新 directed 版本已经把逐类来源关系保留到 U_c 中，不能再把它描述为同一个并集失效问题。本次推进的是：从“按类限定参数来源”进一步到“按类限定要学习的响应”。改变一个类的来源，会改变该类的教学目标；服务器仅仅持有全部 donor 缓存，不会改变这种关系。

共享学生仍存在类别间耦合，逐类构造目标不会自动消除最终损害。应把可检验主张限定为“在教学内容中排除已观测到的负响应，并尝试共同学习正响应”，不能写成“彻底消除了负迁移”。

## 8. 候选创新落在哪里

建议围绕一条核心主张组织论文：

**在目标标签稀缺且来源客户端缺少该标签时，以共同共享模型为参照，将来源更新转化为目标条件的正向判别增量，并通过类等权响应蒸馏转化为共享模型的学习支持。**

三个具体区别是：

1. **来源能力的定义：** donor 不必是完整的目标类教师，只需在目标端展示可利用的增量响应。
2. **迁移对象的定义：** 从原始参数及其任意线性变换，改为目标类—竞争类关系上的基准相对增量。
3. **共享方式的定义：** 先按目标类构造各自可信的监督，再由一个共享学生联合学习；来源归属保留到监督端。

非负截取、蒸馏、双视图、间隔损失或类等权都不是单独的创新。候选贡献在于这些设计如何针对“缺标签来源的局部正响应不能直接等同于可提交共享更新”形成一个具体机制，并且带来可归因的效果。

## 10. 实现范围与最低证据要求

现有的普通本地训练、FedAvg、A 更新、测试分组和共享推理模型继续作为上下文。B 需要改动四处：

| 位置 | 工作 |
|---|---|
| donor 探测 | 增加原始间隔、逐样本 logits、第二视图及来源得分 |
| 正响应构建 | 保存按类来源、加权增量、跨视图一致部分、基准相对目标 |
| 迁移训练 | 由 C 校准改为共享 B 的响应蒸馏与真实尾类监督 |
| 结果记录 | 保存外部正响应覆盖、共享学生学到的比例、逐类判别变化及固定 Tail20 |

这需要重写 B 的校准阶段，不是只修改一个正则系数。目标数据不需要上传原图，原始 donor 更新也可沿用现有缓存；额外视图与 B 参数优化的实际成本仍需测量。

为证明外部知识起作用，至少需要回答两个问题，而不是只比较新旧名字：

- 与相同步数、视图、预算及基准参考下的额外尾类训练相比，来源响应是否提供额外收益？可用 r=0 的匹配对照回答。该对照显式执行相同训练日程，不触发主方法的“全事件零响应则跳过”规则。
- 保持每类响应幅度分布、但在该类样本间打乱响应后，效果是否下降？若没有差异，收益可能主要来自置信度增益或额外正则，而不是样本相关的外部判别知识。

这两项是提出贡献所需的最小归因问题，本次不启动实验。主指标仍是固定 Tail20 的最后20轮测试均值；不能用响应拟合率或训练受损数替代它。

## 11. 设计风险与决策边界

- 正部截取会产生乐观偏差；先对选定来源加权再截取、双视图一致性可以限制部分噪声，但没有独立验证作用。
- 当前 probe 的增量可能太弱或只改变置信度。若正响应无法提供超过 r=0 对照的收益，不能将额外尾类训练收益归给 donor。
- 不同输入上的目标可能无法被一个共享 LoRA 同时拟合。响应是软目标，保留分类监督和受限更新幅度；不预设全部关系均能改善。
- 每类仅4—9张训练图片，仍可能过拟合；训练样本上的判别间隔改善也不保证测试提升。
- 本方案可能丢弃有价值的非目标关系，也可能比参数重组更有效或更差。是否值得固定，由学习效果与归因对照共同决定。

本方案值得优先实现的理由，是它把外部来源真正转化成了新的、可追踪的监督内容，使 B 的目的从“在 donor 子空间里再优化尾类损失”推进为“学习缺标签来源提供的正向判别支持”。这是一项研究假设，尚不是实验结论。
