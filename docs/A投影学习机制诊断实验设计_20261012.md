# A 投影学习机制诊断实验设计

日期：2026-10-12。状态：已按老师的补充口径实现诊断入口与 CPU 校验，正式 GPU 数据尚待服务器运行。本文为本仓库的独立机制实验协议，不改写现有正式基准、训练合同和历史结论。运行说明见 [诊断工具](../tools/a_projection_diagnosis/README.md)。

目标是检查：在给定样本预算和固定读出规则下，A 输入子空间中类别判别信息的线性可读性是否变化；进一步区分本地学习、聚合和当前模型利用这些方向的作用。测量对象是预设输入摘要，不能代表全部非线性信息。A、B 均指 LoRA 因子，普通 A 指 B3 后 A1 的交替训练；Full-CP、Av2 均不作为本轮主诊断对象。

三项主实验依次检查跨轮信息变化、同轮本地与聚合变化、仅改变 A 聚合权重的即时效果。另安排一个无需完整重训的行空间干预，避免只凭相关曲线归因。第一阶段尽量只读服务器已有状态；本文件不构成已经启动新训练的记录。

## 1. 需要区分的解释

| 编号 | 候选解释 | 本轮能直接检验什么 |
|---|---|---|
| H1 | A 的行空间逐渐不利于部分尾类区分 | 固定模块输入后，正交投影中的类别可读性是否下降 |
| H2 | 本地 A 更新本来有帮助，但聚合后帮助减弱或方向改变 | 同一起点的各客户端提案与其聚合的类别响应 |
| H3 | 加权直接改变 A 阶段的方向，缓解上述问题 | 固定 B、起点和全部本地提案，仅更换 A 聚合权重 |
| H4 | A 行空间仍含有信息，问题主要在坐标作用、B、上游或后续计算 | 投影读出与完整模型表现分离；行空间内外更新干预 |

H1 至 H4 可以并存。A 子空间问题不等于整个 CLIP 的类别信息消失。每层满足 Row(BA) 包含于 Row(A)，但预训练分支 W0x 仍在；A 的梯度也经过 B 和后续网络。

成功标准是得到能够改变方法选择的证据，不是必须观察到尾类投影下降。若测量无力区分，结果应为“尚未定位”，不能强行二选一。

## 2. 轨迹与固定训练条件

| 轨迹 | 配置 | 用途与执行优先级 |
|---|---|---|
| C-F | Client-LT，普通 A，FedAvg | 主参考；先检查现有服务器状态 |
| C-T | Client-LT，普通 A，TailRW16 | 加权轨迹参照；与 C-F 配对 |
| D-F | 固定边际 matched Dirichlet，普通 A，FedAvg | 第二阶段的客户端分配机制对照；同协议权重存在时复用，否则另行补采 |
| C-J | Client-LT，普通 A，joint | 已有权重可用时作补充；不为它新增完整训练 |

第一阶段 C-F、C-T 已足以检验本配置下 H1、H2、H3。未完成 D-F 前，不声称 Client-LT 特有或强于另一划分。D-F 只固定全局类别数量和每个客户端容量，仍同时改变支持、共现及样本归属，不能把差异唯一归因于支持客户端数。

当前正式 Dirichlet 基准是 noniid-labeldir-fine；本机制实验的 matched-dirichlet 是单独对照，不替换、不重命名该基准。旧 CE／周期刷新 matched 轨迹与当前 LA／逐轮 A 轨迹不能组成主对照。现有旧桥接启动器拒绝新建 matched-dirichlet，不能直接照搬其命令；实现时需独立入口和协议。

固定条件沿用当前普通 A：CIFAR-100-LT、IF=.01、ViT-B/16、vision top3 q/v、rank4、alpha1、实际 scaling=.5、dropout0、FP32、30 客户端每轮全参与。文本、提示参数、logit scale 和主干固定。全局训练频数 LA，tau=1，测试使用原始 logits。

- B 阶段：每客户端三个 epoch，原 SGD、lr=.001、momentum=.9、weight decay=.0005 及原调度。
- A 阶段：1—90 轮，每客户端一个 epoch，固定共同的聚合后 B；新建 SGD、lr=.001、momentum=.9、weight decay=0。
- 91—100 轮仅 B。无 Full-CP、Av2、额外 B 迁移或类别残差头。
- C-T 的整条历史轨迹同时对 A、B 加权，只用来研究长期关联；E3 才隔离当轮 A 的加权。
- 当前 seed42 划分含 10847 张训练图，最少每类 5 张。C-F/C-T 必须逐样本核对划分、初始化、训练日程和环境。
- D-F 还需核对全局 raw ID 集合、n_c、逐 client ID 的 n_j、参与顺序和初始化完全相同；客户端成员归属应不同。沿用 alpha=.5，不按性能挑划分。

## 3. 状态、样本和测量契约

**观察轮次。** E1 使用提交状态 t=0、20、50、80、90、100。主变化量预先固定为 t=80、90 的平均减 t=20；50 展示中期，0 展示起点，100 检查 B-only 阶段。不用测试峰值选早期锚点。E2、E3 和行空间干预使用 20、50、80 轮的普通 A 事件。

**模块。** 六个投影分别为 visual block 9、10、11 的 q/v，模块键从模型实际注册参数解析并留档，不能只依赖手写名称。输入取各 q_proj/v_proj 的 forward pre-hook，即 LayerNorm 后、线性投影前的 token；不能误取 block 输入或注意力输出。

block 9 是第一个 LoRA block。若取样位置上游全部冻结，且确定性预处理、eval 模式和批次划分固定，其输入应跨轮一致；实现检查实际 q/v pre-hook 输入摘要的逐字节哈希。block 10、11 的输入可随上游 LoRA 改变。

**拟合数据。** 从实际训练 manifest 中按类无放回取 min(32,n_c) 张，按 SHA256("A-projection-v1|20261012|raw_id") 排序选择。seed42 当前 manifest 得到 2472 张。三个实验、所有候选和所有拓扑共用 raw ID 清单，独立于客户端归属。每类总拟合权重相等，类内等权；不复制尾类图片，不把增强视图作为独立样本。

**评价数据。** E1 使用完整官方 10000 张测试图。E2、E3 和干预的主连续响应采用固定审计子集：每类按独立固定哈希取 20 张测试图，共 2000 张；同类剩余 80 张共 8000 张用于 E3/干预聚合候选的预先约定复核。20/80 拆分是配对诊断面板，不是新训练集。所有 E3 和干预候选均在剩余面板复核，不按前一个面板表现选“赢家”。

这批测试数据已经在历史研发中被观察过，本轮是机制探索，不是全新盲测。测试标签只用于离线评价；不训练 probe、不调正则、不挑轮次、不改变客户端权重、不训练新方法。以后开发新损失需要另设训练侧验证协议。

**类别分组。** 继承原协议的 Head20、Middle60、Tail20 清单，按类平均，并报告全部 100 类。不要用测试结果重新分组，也不要将 Tail30 的新训练划分混入。

**行空间表示。** 对每个 A 在 FP64 做 SVD，取相对奇异值大于 1e-6 的右奇异向量组成正交行基 Q_A。记录全部奇异值和数值秩；秩不足 4 时补零特征维，不用 QR 人为补出不存在的方向。P_A=Q_A^T Q_A。

主读出特征固定为 CLS 与全部 patch token 均值的投影拼接，共 2r=8 维。六个模块分别报告，六者拼接的 48 维读出为辅助量；不比较池化方案后择优，不只报告最符合故事的一层。

主探针是类别均衡 ridge 线性读出：拟合 one-hot 标签，截距不正则。仅用拟合样本，以每类总权重 1/100 做加权中心化，再用一个全局 RMS 标量归一化，不按通道单独标准化；这样正交换基不改变几何或 ridge 惩罚。lambda 固定 .01，不增加正则扫描。预测取最大读出分数；ridge 分数不能当成 CLIP margin 或概率。

具体目标固定为 sum_i w_i ||z_i W+b-onehot(y_i)||_2^2 + lambda ||W||_F^2，其中 w_i=1/(100 m_{y_i})，m_c 是拟合清单中类c的样本数，权重和为1。RMS为 sqrt(sum_i w_i ||z_i-mu||_2^2 / d)，d为特征维数。逐类同时保存未正则化的测试读出平方误差；误差越低越好，辅助检测单轮更新尚未改变argmax时的信息变化。

各状态重新拟合读出，训练样本、规则和正则相同。读出仅用于离线测量，不装回 CLIP。若特征加权方差为零，记录退化并使用训练类先验，不除以零。

首版不增加完整 token 展平读出。若预设摘要的探针整体分辨能力很弱，结论是测量不足以定位；即便读出未下降，也不能证明所有非线性信息完好。尾类拟合样本较少，因此主要比较同一批样本上的跨轮及同起点变化，不用低绝对精度单独判断 A 对尾类不好。

完整模型的主功能指标是每张图的未缩放余弦 margin：正确类相似度减去最强错误类相似度；另报告 raw CE、准确率及类别均值。同起点比较按 Head/Middle/Tail 报告 lost（起点正确、候选错误）与 gained（起点错误、候选正确）。probe 精度和模型精度分列，不相减解释成知识量。全部完整模型评价均正常前向，不注入缓存的中间输入。

## 4. E1 固定输入下的跨轮投影诊断

所有轨迹使用同一个初始化模型产生固定参考输入 X0，先确认初始化一致。每个模块计算三种组合：

| 组合 | 测量 | 解释范围 |
|---|---|---|
| Q(A_t) X0 | 固定输入、改变 A | 主检验：A 行空间自身变化 |
| Q(A_0) X_t | 固定 A、改变输入 | 上游变化的辅助诊断 |
| Q(A_t) X_t | 当前 A、当前输入 | 当前系统实际投影信息 |

block 9 的前后两种含 A_t 的组合应一致，固定 A_0 的组合应恒定。后两层的固定 X0 属于反事实测量，可能偏离当前激活分布，因此必须同时报告自然输入结果，不能单独用它断言当前模型丢失信息。

对每模块/组合/组别 G 记 probe 准确率为 S_G(t)，主变化量为 D_G=(S_G(80)+S_G(90))/2-S_G(20)。报告 Tail20、Head20、Middle60 的绝对变化；D_T-D_H 只衡量相对失衡。仅有头类进步更快而 D_T 不下降，不称尾类信息丢失。

C-T 与 C-F 比较 D_G 的差；有 D-F 后再比较两种拓扑 D_G 的差。主图同时展示 probe 和完整模型曲线，但不要求全部轮次单调。第90和100轮固定输入的 A probe 应一致，因为 A 不再更新；最终模型的变化应单独解释。

记录投影子空间距离、奇异值、A 参数范数及有效 BA 更新范数作为辅助。只有子空间旋转或范数变化，没有类别读出变化，不能证明偏头或伤尾。

**判读。** 固定输入与真实输入下尾类读出都下降时，与实际投影可读性退化一致，还要结合模型和干预。若固定输入下降而真实输入稳定或改善，可能是 A 与上游重新匹配，不能称为实际信息退化。若只有真实输入下降，优先检查上游交互；若 probe 稳定而模型下降，优先检查利用方式，同时保留探针能力不足的可能。

## 5. E2 同轮本地提案与聚合定位

首轮只在 C-F 的 t=20、50、80 做全部 30 客户端诊断。每轮从 A 事件读取共同起点 M0=(A0,Bbar)、30 份 delta A_j 及实际 FedAvg 聚合结果 Aq。这里的 A0 指该轮起点，不是初始化 A。

每个本地候选 Mj=(A0+delta A_j,Bbar) 一次性替换六个 A；其余参数与 M0 相同。按 selected_client_ids 对齐更新、计数和权重，不依赖列表位置等于 client ID。历史事件的 A 阶段只保存增量，因此重建本地 A 有 FP32 舍入限制；诊断结果保留提案来源，不宣称逐位恢复原始客户端终点。

两条测量并行：

1. 固定该轮 M0 的模块输入，对 A0、每个 A_j、Aq 计算相同的投影读出，隔离各模块输入的变化。
2. 将全部 A_j 放回完整模型，在相同 2000 张审计图上测每类 cosine margin、CE、准确率。这里允许上游 A 变化产生其真实作用。

同轮作用可能很小，E2/E3的连续读出误差与完整模型cosine margin必须和准确率一起报告；准确率不变不等于更新无作用。一次模型不变的重复评估用于记录实际数值噪声。

对类别 c 定义 f_c(M) 为审计图平均 cosine margin：

    u_jc = f_c(Mj) - f_c(M0)
    u_qc = f_c(Mq) - f_c(M0)
    local_mean_c = sum_j q_j u_jc
    nonlinear_gap_c = u_qc - local_mean_c

还计算 pos_c=sum_j q_j max(u_jc,0)、neg_c=sum_j q_j min(u_jc,0)，并按是否实际持有类别 c 分解。持有者身份只能由 n_jc>0 定义，不能把客户端27—29机械地当成所有尾类的唯一来源。

local_mean 是客户端作用的加权描述，完整模型非线性意味着它通常不等于聚合模型作用；不能把差值直接命名为矩阵聚合错误。probe 准确率也不具有可加性。本 A 阶段 B 共同固定，sB(A+sum_j w_j deltaA_j)=sum_j w_j sB(A+deltaA_j) 严格成立，因此不能归因为 A/B 分别聚合的乘积误差。

**判读。** 某些本地提案对尾类有益而 u_qc 不佳，支持帮助在聚合中不足，但需结合其权重和负向作用；不能拿最好的单个客户端与聚合相比就宣布聚合失败。如果投影读出已在多数本地提案中下降，优先检查本地 A 目标；如果本地/聚合 probe 均稳定而完整模型受损，优先检查利用和多层联动。

若需解释拓扑差异，对 D-F 的相同三个轮次重复 E2。不同拓扑各自的状态已不同，这是各自轨迹上的分阶段诊断，不是同参数的拓扑因果干预。

## 6. E3 仅改变 A 聚合权重

复用 E2 的起点和全部提案，固定同一个 Bbar。所有候选离线评价、不提交后续训练。

| 候选 | A 状态 |
|---|---|
| No-A | A0 |
| FedAvg | A0 + sum_j q_j delta A_j |
| TailRW16 | A0 + sum_j wT_j delta A_j |
| joint | A0 + sum_j wJ_j delta A_j |

q_j=n_j/N；仓库 TailRW16 实际定义为 wT_j=(n_j+16 n_j,T)/(N+16 N_T)，不是将某三位客户端统一乘16。joint 沿用现有 lambda=.1 的计数求解器与固定向量，不搜索强度、不使用 floor16。权重必须由这一份 partition 的计数生成或严格匹配的归档恢复，不能跨拓扑复制。

每个候选先报告真实幅度的结果，再做等有效范数比较，以避免加权效果只是缩步或放大。对候选 w：

    dA_w = sum_j w_j delta A_j
    nu_w = sqrt(sum_l ||s_l Bbar_l dA_w_l||_F^2)
    nu_star = min(nu_k for k in this_panel if nu_k > 0)
    dA_w_matched = (nu_star / nu_w) dA_w

六模块统一乘同一个系数，所有系数不超过 1。零有效范数候选单列，不参加最小值；不因一个零候选跳过其余非零候选。保留原始与等幅结果。最小值小于 1e-10 或小于面板最大值的 1e-3 时标记 low_power，不能把无差异当作否定。等幅只能排除“跨层有效更新总范数单独解释差异”，不匹配实际激活变化或各层敏感度。

沿用 E2 固定输入 probe 和完整模型指标，预先规定的剩余8000张复核只需评价这几份聚合候选。模型的测试收益不返回权重求解器。

**判读。** 加权在相同起点、提案和 B 下改善尾类投影与模型响应，且等幅后仍存在，支持当轮 A 聚合方向的作用。只改善模型、不改善 probe，不能解释成恢复投影信息。真实幅度有效但等幅后消失，优先考虑步幅解释。无即时收益不否定加权通过 B 阶段或多轮轨迹产生作用。

这项实验不回答“只给 A 加权100轮是否足够”。若后续确需量化长期 A/B 权重来源，另立 A权重×B权重的完整2×2轨迹；不将其自动纳入本轮。

## 7. 行空间干预 将相关性推进到局部因果证据

此检查固定纳入 C-F 的20、50、80轮，使用其 FedAvg 的 dA，不新增100轮训练。对各层该轮起点的行空间投影 P0：

    dA_parallel = dA P0
    dA_perp = dA (I-P0)

比较 M0、A0+dA、A0+dA_parallel、A0+dA_perp，Bbar 均固定，六层同时应用。前两者复用 E2。完整更新、parallel、perp 同时给出实际幅度与三者共同最小非零有效范数的等幅结果；规则与 E3 相同。

因为 A0=A0P0，A0+dA_parallel=(A0+dA)P0，候选行空间包含于原行空间；只有秩保持时二者才相等。实现检查数值秩及同秩探针预测不变性，降秩单列。令 D=dA_perp，则 A0 D^T=0，且 (A0+D)(A0+D)^T=A0 A0^T+DD^T；空间外分量同时改变行空间与 Gram/尺度，不能称为纯旋转。

如果parallel分量很小，共同范数会把其余候选也缩到几乎无可测影响。此时将等幅干预标为测量能力不足，不把“都没变化”当作否定方向作用，也不为了获得差异而事后放大步长。

这个实验检验行空间外分量是否参与当轮损害：若完整/perp 损害尾类，parallel 较轻，同时伴随读出下降，且等幅与剩余样本复核相容，则获得局部机制证据。若 parallel 也有损害，应检查有效映射或多层配合，不能直接推断 B 容量不足或必须新增方法 B。始终同时看 lost/gained；更稳定可能伴随新学习减少。即使空间外分量有害，也不直接决定永久冻结行空间。三个轮次均无可测损害时，不宣称排除了长期累积机制。

同步检查固定输入的 parallel probe 应保持一致；否则先检查数值秩、读出归一化、正则和实现。这里的完整模型可以改变，因为 B 固定而 A 的行变换会改变 BA。

联合改变六层包含多层交互。只有需要定位具体模块时，才另立单层干预，不从本轮全层结果指定唯一层。

## 8. 结论规则与统计边界

| 观察组合 | 可采用的结论 | 下一步方法方向 |
|---|---|---|
| E1固定输入尾类下降，E2定位到A阶段，行空间干预与损害一致 | 输入子空间变化是当前配置中的一条有证据的退化路径 | 将类别判别需求加入A的学习过程 |
| 固定输入下降，但真实输入稳定或改善 | 可能是 A 与上游重新匹配，不能称实际投影信息退化 | 结合当前输入及完整模型继续判断 |
| 本地提案有帮助，聚合后帮助不足；E3等幅调权改善 | A聚合组织有作用 | 研究实际类别响应与聚合方向 |
| 只有当前输入probe下降，固定输入probe稳定 | 上游变化更值得检查 | 多层协同或上游功能保持 |
| probe稳定，模型下降，parallel仍受损 | 行空间覆盖不足暂不是主要证据指向 | A/B利用、尺度和分类目标 |
| probe下降但模型稳定/改善 | 被测信息下降不一定限制当前任务 | 不直接优化这个probe作为方法目标 |
| 各模块结果冲突或探针整体分辨能力弱 | 尚未定位 | 报告冲突与测量能力限制 |

判断时同时看尾类绝对变化、头中类代价、逐类分布和完整模型响应；不以一个层、一类或一种读出胜出为结论。预先报告三个事件各自方向，事件均值只是描述性汇总，不将事件当成独立训练种子。

seed42 为探索性诊断。对 E1 和候选差值可按类别内重采样相同图像ID、保持两候选配对，固定1000次 bootstrap（seed20261012）；这只量化给定模型与已拟合probe下的测试样本不确定性，不覆盖训练、划分或probe拟合的不确定性。主要模型差值、probe拟合样本数和逐类结果同时给出，不用轮次t检验，不以逐类100个数当作100次训练重复。

只有固定输入、真实输入、完整模型与局部干预的证据相容，才讨论该配置中的机制支持。要写一般性结论，后续补独立训练种子；固定 split_seed42 时只能检验训练随机性，不能宣称跨划分稳健。发现负结果也按原计划保存，不事后改主轮次、类组或 lambda。

## 9. 工程输入和可复用接口

当前本地普通 A／Av2 轻量归档没有 .pt/.pth。不能从预测恢复输入子空间。最少向原服务器查找：

- 各轨迹 checkpoints/base_model.pt；原配置、partition_manifest.csv、protocol、聚合权重及运行环境。
- E1 的提交状态0、20、50、80、90、100。普通 A 的各A事件 actual_after_lora_state 可恢复相应提交状态；100轮用普通B事件终点。只保存最后一次的 sfra_last.pt 不足以恢复历史。
- E2/E3/干预的 events/r020_c000_main_refresh_A/state.pt，以及050、080；每份必须含 anchor_lora_state、actual_after_lora_state、local_factor_deltas、selected_client_ids、server_weights 和计数。
- 相同轮次的B事件是可选补充归因数据，不是三项实验的最低输入要求。

base_model 包含完整冻结参数；事件中保存的是 LoRA 状态，恢复时必须合并并检查键、shape、dtype和状态哈希。不得将事件张量直接当成完整CLIP state_dict。

| 仓库接口 | 复用方式 |
|---|---|
| trainers/cliplora.py::build_cliplora_model | 恢复实际模型和六个LoRA模块 |
| tools/a_learning_schedule/config.py::parse_archived_config | 恢复历史配置中的tuple类型 |
| utils/cliplora_bridge_audit.py::BridgeAudit.save | 恢复共同起点、提案、终点及聚合身份 |
| utils/cliplora_a_refresh.py::aggregate_refresh_deltas | 重建实际FP32增量聚合 |
| utils/cliplora_a_refresh.py::update_diagnostics | 复用有效范数、原空间外更新等辅助记录；不能替代类别probe |

读出和SVD用FP64；模型沿用原FP32。评估必须使用独立模型或完整恢复原状态、training mode及随机状态，不能修改正在训练的模型或消耗其随机流。

实现时增加四项有意义的校验：相同A相同输入读出一致；可逆换基保持行空间probe；parallel干预保持行空间probe；原权重重建聚合与事件实际终点在原精度容差内一致。打乱拟合标签而保持测试标签不变，作为probe泄漏/异常的诊断对照，不硬规定有限样本精度必须等于1%。

固定参考输入按图像批次生成 CLS 和 patch 均值，再投影到所有候选，释放高维 token；只缓存低维特征和预测。客户端完整模型只在 2000 张面板评价，剩余 8000 张复核全部预定聚合候选。记录前向图片数、probe 拟合次数、耗时和缓存大小；不承诺未经测量的小时数或加速倍数。

## 10. 交付物与实施顺序

实现目录为 tools/a_projection_diagnosis/，独立入口为 scripts/run_a_projection_diagnosis.py；inventory/preflight/smoke/run/server/summary/pack 分别用于核对、检查、真实模型小样本冒烟、正式诊断、串联执行、汇总和结果打包。恢复与运行命令见工具 README。

执行支持最多4张 GPU：两个轨迹的 E1 各是一项任务，C-F 的20/50/80轮分别是一项任务，共五项。`--stage server --gpus 0 1 2 3` 用队列分派，每 GPU 同时只运行一项任务，先完成者领取剩余任务。缓存、环境、成本和模型实例按任务隔离；同一事件的全部候选保留共同起点和同批提案。GPU 编号相对于已有 CUDA_VISIBLE_DEVICES，不改变采样、种子或任何测量条件。并行吞吐尚待服务器实测。

建议输出到 output/a_projection_diagnosis_v1/，至少包含：protocol.json、artifact_inventory.csv、probe_fit_manifest.csv、audit_eval_manifest.csv、representation_curves.csv、local_class_response.csv、a_weight_counterfactuals.csv、rowspace_interventions.csv、numerical_checks.json、costs.csv，以及汇总判断。

每行测量至少记录轨迹、种子、拓扑、轮次、阶段、模块、输入来源状态、A来源状态、候选、拟合清单哈希、评价清单哈希、数值秩、读出lambda和类组；不能只输出一个Tail曲线。

实施顺序固定为：

1. 状态预检：确认服务器C-F/C-T和可能已有D-F的权重、事件和协议；缺失条目标为unavailable，不作为实验失败。
2. C-F/C-T的E1；先校验block9固定输入和90/100恒等，再读取机制曲线。
3. C-F三个起点的E2、E3、行空间干预及预定8000张复核。已有C-J完整状态可补E1，不新跑joint。
4. 完成D-F后重复E1和E2，回答客户端分配是否加剧已定位的现象。
5. 根据上述固定判读规则确定新A目标；另立训练侧验证与多种子方法实验。

恢复顺序固定如下。原模型与提案都在时直接离线诊断；模型在而提案缺失时，从同轮 post-B/pre-A 事件恢复，或用上一轮 A 与本轮 B 合成 preA_t=(A_{t-1},B_t)，仅重新生成三个起点各 30 份 A 提案，标为“从历史共同起点重新生成的一组配对提案”，不冒称历史精确复现。为此检查 19、49、79 轮 A；明确映射可写入源目录 projection_states.json。只有模型也不存在时，才先补采一条普通 A＋FedAvg 轨迹。C-T 的长期结论仍需要 C-T 轨迹，不能用即时加权代替；matched Dirichlet 保留第二阶段。补采用新输出目录。
