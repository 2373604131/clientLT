# 方法 B 保留来源方向与利用来源结构的判别实验

日期：2026-10-08。状态：新增路线、统一求解器、独立训练/回放入口与汇总代码已实现，已做 CPU 验证；尚未运行真实 CLIP/GPU 实验。本文件定义固定实验协议，不是已有实验结果。实际命令、产物与验证边界见[代码与运行说明](方法B_路线实验代码与运行说明_20261008.md)。

要区分的两条路线是：P，保留客户端原始更新方向，通过非负组合利用已有帮助；C，允许完整矩阵变换，利用客户端更新的列空间重新学习补充更新。自由残差 F 检验是否需要来源，随机结构对照检验真实来源是否有特别价值。完整方法 A 始终保持固定。

## 1. 可以回答的问题与边界

| 问题 | 决定性比较 | 不能替代它的证据 |
|---|---|---|
| 保留原始方向是否已经足够 | P 与 C 的同状态诊断、完整训练 | 单个 donor 探测为正 |
| 放开 C 的哪种自由度有用 | P → M → S → C 的递进对照 | 只比较标量与完整 C |
| 使用来源是否值得 | P/C 与相同反馈的自由残差 F | 只比较 A 与 A+B |
| 真实来源结构是否有特殊价值 | 候选 W 与同维度随机旋转来源 W-rot | 仅改变 donor ID 顺序 |
| 当前两步是否混入优化不足 | 同一诊断分支第 2 步与第 8 步 | 单看总目标下降或盲目增加完整训练预算 |

P 与 C 的函数空间是包含关系，不是互斥假设。C 胜过 P 可以说明额外自由度有用；不能仅凭这个结果证明“学到了来源知识”。P 接近 C 只支持优先考虑更简单的实现，不证明所有变换都无用。

P 的非负系数只保证保留原始方向，不保证每个被使用的来源曾经单独探测为正，也不保证组合后每个类别都受益。本轮将“原始方向是否有用”与“现有正收益探测能否选准来源”分开；后者由分开的 fit/诊断探测检查，不能直接由 P 的最终精度推出。

本次固定当前共享 B 的反馈范围和全部 30 个普通更新，只判别来源使用方式。对每个类别严格限制为“目标组外且缺该类标签”的路线是另一项变量，不能同时更改。这套核心比较不能单独证明缺标签来源的因果贡献。

## 3. 实验组与参数空间

以下 R_l 为模块 l 的补充 LoRA-B 残差，D_jl 为同轮客户端 j 的原始 B 更新，m 为来源数。省略 1/m 的写法与下表空间等价，系数不设固定和为 1。

| 组名 | 残差形式 | 自由度与作用 | 用途 |
|---|---|---|---|
| N | R_l=0 | 无补充 | 同状态零更新及完整 A 基线 |
| P | R_l=sum_j alpha_j D_jl，alpha_j>=0；同一 alpha_j 跨模块共享 | 当前 30 个系数；保留整个客户端更新方向 | 路线一主组 |
| M | R_l=sum_j alpha_jl D_jl，alpha_jl>=0 | 当前 180 个系数；允许各模块单独缩放 | 分离逐层调权的作用 |
| S | R_l=sum_j alpha_jl D_jl，alpha_jl 可正可负 | 当前 180 个系数；允许模块更新反向 | 分离符号翻转的作用 |
| C | R_l=(1/m)sum_j D_jl C_jl，C_jl 为完整 r×r | 当前 2,880 个名义系数；允许内部线性组合 | 路线二主组 |
| F | R_l 为自由矩阵，形状与 B_l 相同 | 当前 18,432 个系数；不使用来源基底 | 同反馈直接校准 |
| O | 现有完整 C + Adam lr=0.3 + C 正则 0.001 | 沿用旧更新算法 | 旧实现复现及优化差异桥接，不混入纯空间对照 |

可行空间满足 P ⊆ M ⊆ S ⊆ C ⊆ F。报告实际数值秩；2,880 是 C 的名义参数数目，不必等于可实现残差的维数。

P 保留的是整个 donor 的原始方向；M 只保留每个模块内部方向，不能将 M 获胜写成“整体方向完全不用改变”。S 获胜只能支持允许反向的组合；不能宣称完整 r×r 变换必要。

O 用现有参数化，P/M/S/C/F 用下节共同求解器。C 对应完整 C 能实现的残差空间，其运行算法与旧 O 不同。这一设置用于判别表示约束，而不是偷偷把旧 C 的正则与优化器优势或劣势算给来源空间。

## 4. 共同求解器与独立幅度规则

### 4.1 使用有效 LoRA 更新坐标

因 R_l 的参数范数不等于真实权重更新范数，统一使用

    ||R||eff² = sum_l ||s_l R_l A_l||F²。

在每个事件固定 A_l，对其做薄 SVD：A_l=U_l Sigma_l V_l^T。保留非零奇异方向，定义

    X_l = s_l R_l U_l Sigma_l，
    R_l = (1/s_l) X_l Sigma_l^(-1) U_l^T。

于是 ||X||F=||R||eff。A 的零空间不改变本事件的前向，使用上述最小范数代表。SVD 在 FP64 计算；相对奇异值阈值固定 1e-8，记录有效秩及被舍弃部分。普通更新、投影、半径和前向一致使用同一保留空间。

共同优化器对 X 求分类梯度，不对每种参数化分别使用相同名义学习率。这样避免把 C 的尺度、来源更新范数或 Adam 坐标效应误认为路线效应。

### 4.2 独立半径

每个事件用本次普通聚合更新构造

    nu_t = sqrt(sum_l ||s_l (Bbar_l-Bstart_l) A_l||F²)，
    radius_t = rho × nu_t。

主配置 rho=1；同状态敏感性固定 rho∈{0.5,1,2}。nu_t=0 时补充为零并单独记录，不以任意常数补造幅度。

该规则只依赖当轮普通训练，不读取 AB 范数记录或测试指标。它是待验证的工程规则，不预设 rho=1 最优。同状态所有组的 radius 完全相同；完整训练轨迹分叉后，各组 nu_t 可不同，因此称“同一幅度规则”，不称每轮绝对范数完全相同。

### 4.3 每一步

初始 X=0，无动量。主步长 h=radius_t/2。对当前统一反馈批次：

    G = gradient_X L_classification(X)
    Y = X - h × G/||G||F
    Z = project_to_route_space(Y)
    X_next = Z × min(1, radius_t/||Z||F)

G 或 Z 为零时分别跳过该步或保持零；有限性、零范数阈值固定为 1e-12 并记录。每组同一次梯度更新前完成所有反馈端反向，不在客户端循环中更新共享变量。

空间投影：

- P：将全部模块 X 拼接，来源 j 的基向量为拼接后的 s_l D_jl U_l Sigma_l；用非负最小二乘投影到来源锥。
- M：每个模块独立做上述非负最小二乘，然后统一裁剪全局范数。
- S：每个模块投影到这些来源向量的线性张成空间，系数允许正负。
- C：模块 l 令 Q_l 为拼接矩阵 [D_1l,...,D_ml] 列空间的正交基，投影为 Q_l Q_l^T Y_l。这与完整 C 的可实现空间相同；可用最小范数解重建 C 校验。
- F：不做来源投影，仅执行共同的范数裁剪。

对锥/线性子空间，先做欧氏投影再做全局径向裁剪保持对应可行性。NNLS 的停止条件采用归一化 KKT 残差 <=1e-6；最大 10,000 次低维内循环，未达标标记失败，不静默使用近似失败结果。QR/SVD 的秩阈值固定，所有数值求解设置写入日志。

上述求解是机制对照的新训练规则。它不保留旧 C 的专属正则；统一范数限制承担幅度控制。各组实际上传的是共同残差梯度，不能按 C 的名义系数数量伪报低上行成本。若最终采用 C，可另行工程化压缩反馈；压缩版需证明更新等价。

### 4.4 两步与八步

同状态诊断从同一个零点运行 8 步，同时保存第 2 步和第 8 步。第 3–8 步循环使用原两批 fit 图片，h 和 radius 均不变；不把图片复用称为更多独立样本。诊断预算多出的六步不并入两步算法成本。

完整训练的主配置始终为 2 步、rho=1。若 C 只在 8 步占优，结论是其优势依赖更大预算；不能把 8 步 C 与 2 步 P/F 混比后宣布路线二获胜。是否研究 8 步部署另立版本，全部候选给同等预算。

## 5. 第一阶段 同状态机制实验

### 5.1 状态来源与材料

预先固定第 30、60、90 轮，覆盖早、中、后期。所有候选从同一事件的普通聚合后模型开始；不连续提交不同候选，不改变之后训练。

优先采用同一 A-only 轨迹的普通 B 事件；若服务器仅保留旧 AB 完整事件，可统一采用该 AB 轨迹并在计划中冻结。不得按每个事件的效果在 A-only 与 AB 之间择优。后者的 60/90 轮状态已受旧 B 历史影响，完整训练阶段负责检查候选各自的轨迹。

必须具有基础模型、轮初及普通聚合后的 LoRA、全部原始 D_jl、模块/客户端顺序、样本量权重、类别计数、数据身份、LA 先验、采样清单及执行配置。仅有 C、CSV 或最终参数无法反推全部原始更新。

本地 `output/ab_decision_42_0_3407_analysis` 未检索到 .pt/.pth。应先检查服务器原始运行目录的 `events/rXXX_c000_main_normal_B/state.pt` 和 `checkpoints/base_model.pt`。旧 AB 还应有迁移 `commit.pt`。旧重放脚本支持其已有 E 组预检，不支持本文件的新组。

若服务器材料也不存在，只补采一条 seed42 的 A-only 参考轨迹并在 30/60/90 轮存事件，不为每种候选重复普通训练。seed3407 的同状态机制复核可在后续本来需要的完整新运行中采集共同事件；不把无法重放标作实验失败。

### 5.2 本事件 fit 与诊断样本分离

按全局训练图片唯一 ID，在原反馈端可用训练样本中逐类确定性分成两折。增强视图和图片的重复抽样必须随同一 ID 分组。每个有至少两张不同图片的类别两折均至少一张；不满足者标记未覆盖，不补重复图片假装独立。

具体切分：每类唯一图片 ID 排序后，用独立 RNG SeedSequence([training_seed,class_id,202610081]) 打乱，前 floor(n/2) 张为折0，其余为折1；同一 seed 跨事件沿用该切分。诊断尾类使用诊断折的全部可用尾类图片；非尾类在每个反馈端最多16张，按固定类别轮换规则抽取并保存身份。原始来源探测只评估尾类，每个客户端—类别每折最多8张；非尾诊断不为每个 donor 重复全量计算。保持所有候选的诊断清单完全一致，未覆盖类别不填零。

一次以折 0 为 fit、折 1 为诊断，另一次反过来。来源探测、来源资格判断及校准只使用 fit。原始 D_jl 来自正常本地训练，不因诊断切分重新训练。按原两批、每端尾/非尾容量规则从 fit 采样；两组都有样本时沿用 0.35/0.65，只剩一组时对现存组取均值；两组都空则跳过该端，对非空端等权。这个稀疏处理只用于本事件诊断，必须逐折记录，所有候选完全一致。

诊断折不参与梯度、步数、半径选择或提交判断。它没有参与本次 B 拟合，但可能参加过此前普通联邦训练，不能称为从未训练过的独立测试集。两折与多个事件也不是独立种子。

完整训练阶段恢复原全部反馈采样，不永久拿走尾类训练数据。诊断折定义不用于修改正式 Tail20 测试集。

### 5.4 随机结构反事实

在主配置 rho=1、2/8 步，对 P 和 C 分别增加旋转来源对照 P-rot、C-rot。每个模块用同一个数据无关随机正交矩阵 O_l 左乘所有来源：

    D'_jl = O_l D_jl。

不旋转模型输出、基底模型或标签。该操作保持每模块来源矩阵的秩、奇异值、来源间 Gram 关系及有效更新范数，改变其与当前模型/任务梯度的对齐。C-rot 的可行维数与 C 一致，不能仅重排 donor 名称或作不改变列空间的右旋转。

同状态诊断每种旋转组固定 3 个随机抽取，种子由 training_seed、event、module、null_index=0/1/2 及固定 domain=20261008 派生；两折共享同一套旋转。报告三个结果与均值，禁止挑最差随机来源衬托真实来源。

42 的两种旋转组为 2×3×3×2=36 条短分支，288 步；3407 材料齐时相同。它们仅使用主半径，不再做全网格。

真实来源优于旋转来源，支持该任务相关方向/空间有价值；不能单独证明某类语义知识或缺标签数据因果贡献。

### 5.5 必须输出的诊断

1. fit 与诊断折各自的类宏平均 Tail LA、raw-logit ACC、正确类—最大竞争类 margin；非尾相同指标与覆盖类别数。
2. 错→对、对→错、未变正确、未变错误的样本计数；重复视图不作为独立样本。
3. 实际有效范数、半径使用率、对普通更新的比例、与自由 F 更新的余弦；零更新不计算虚构余弦。
4. P/M/S 的系数与活跃来源数；C 的列空间秩及向 S/P 可行空间投影后的剩余能量。剩余能量不是测试贡献，只用于解释自由度是否被使用。
5. 共同起点梯度投影捕获率 ||Proj_space(-G0)||²/||G0||²；只解释一阶几何，不等于泛化质量。P 用锥投影。
6. 来源原始探测：分别测 0.1D_j，并补相同有效扰动范数的方向测量；fit 与诊断折分别记录符号、幅度，不把两种尺度混用。
7. O/C 的训练目标轨迹，区分表示空间、旧 C 正则和求解器问题。
8. 每事件总前向、反向图片访问、通信建模、峰值显存、计时；诊断与算法开销分栏。

同一候选最终残差还在 beta∈{0,0.25,0.5,1} 下仅做前向幅度曲线。该曲线不选择正式提交，不把归一化小幅度的好点取代固定主结果。

此阶段不读取官方测试分数来挑 rho、来源或步数。tiny diagnostic ACC 的持平很常见，报告连续损失和 margin，但不能把它们当作 Tail20 成功。

## 6. 第二阶段 完整训练决定实际适合性

### 6.1 开发阶段

seed42 从原初始化完整训练 P、C、F，共 3 组；N 优先复用已核验 A-only。所有组使用主配置 rho=1、两步及同一反馈协议，完整执行方法 A。

第一阶段仅因数值失败、投影不满足约束或前向等价失败而阻止执行。诊断折上的小差异或某个事件收益为负，不足以淘汰一条路线。若公共求解器普遍不能改善 fit 而 O 能改善，应先记录求解器问题、重新设计一个统一的新版本，不能宣布来源路线全失败。

P/C 对 F 的比较都预先登记。若两条来源路线均未比 N 提高，或均比 F 明显差，不追加随机结构的完整训练；保留“当前统一协议下来源路线未建立实用价值”的结论。可报告 O 的历史结果作为参考，但不混算配对均值。

若一个来源候选相对 N、F 均有正增量，则从满足该条件的候选中选定一个 W：按 Tail20 选择，两者都满足条件且 P/C 相差小于 0.10 个百分点时优先 P；这是固定的简化偏好，不是统计等效检验。只为 W 追加一条 seed42 W-rot 完整训练；使用 null_index=0，禁止从诊断三个随机数中择优挑选。

如果 M/S 在机制诊断中提示更简单的自由度已足够，它们仍只是机制证据。要最终采用 M 或 S，需把该候选加入相同的完整训练与确认流程，不能直接用短分支替代正式指标。

### 6.2 配对重复

在 seed42 显示有继续价值后，固定所有设置，在 seed0 和 seed3407 上各运行 P、C、F，共 6 组；N 复用合格 A-only，没有 seed0 A-only 时补 1 组。即使开发时偏好一条路线，确认时仍保留 P 与 C，防止只复核选中的赢家。

若需要主张真实来源有额外价值，选定的同一 W 在这两个 seed 上各补 W-rot，共 2 组。不能按每个 seed 改选 W。三个 seed 的 null_index 都固定为 0，旋转本身随 training_seed/event 变化。

seed42 是开发证据；3407 的旧结果已被看过，此处是锁定新配置后的重复验证，不能称完全未见的保留测试。0 的已知状态也应在实际运行前登记。固定 protocol seed=42 检验训练随机性，未检验不同数据划分的稳定性。

### 6.3 日志与指标

正式轮次 0–100 全部保存；第 0–29 轮各组应与 N 一致。每个 B 事件记录 ordinary_B → after_B → after_A 的训练侧测量，不由这些指标控制提交。第 100 轮没有 A 更新，明确标记，不与其他轮次混解释。

主表为每 seed 的 last20 Tail20、Overall、Head20、Middle60、Non-tail80 以及相对 N、F 的差值；另表给末轮与峰值回落。完整保存逐类收益与损失，不能换 Tail20 定义、只报最优轮或按获利类别筛选。

原始图片、轮次、类别、客户端事件都不充当独立训练重复。报告 seed 级配对差、范围和描述性均值；2 个确认 seed 不足以宣称稳定统计显著性或严格等效。

## 7. 预先确定的判定规则

建议将 0.10 个百分点登记为这次路线选择的实用差异参考线 delta，单位为百分点，不是 10% 或 0.10 的概率值。它是本项目的工程取舍标准，不是理论或显著性门槛。

正式采用某一来源路线至少要求：seed0 与3407对 N 的 Tail20 增量都为正；若声称来源比直接校准有额外精度价值，两者对 F 的增量也都为正且确认均值至少 delta。所有配对数据照常报告；不因某一项未过线删除结果。

Overall、头类和成本共同用于说明取舍。它们不替代预设 Tail20 主指标，也不凭空规定所有组都不能有任何非尾下降。

| 结果模式 | 支持的判断 | 后续选择 |
|---|---|---|
| P/C 在两个确认 seed 的差值绝对值都小于 delta，且 P 对 N/F 有价值 | 完整变换未展示达到预设实用幅度的优势；不等于统计等效 | 优先 P，继续报告 C 的全部结果 |
| C 比 P 更好，而 M 或 S 在机制上已接近 C | 可能是逐层调权/符号自由度在起作用 | 先完整验证 M/S，不直接主张完整 C 必需 |
| C 在确认 seed 对 P/F 均占优，且优于 C-rot | 支持任务相关来源空间与变换路线的价值 | 选择 C；再研究更便宜的等价反馈实现 |
| P 对 F 有优势，且优于 P-rot | 支持真实原始方向可被反馈有效组合 | 选择 P，完整 C 作为更复杂参照 |
| P/C 都不优于 F，F 优于 N | 有效信号主要可由直接额外反馈利用；来源独立价值未建立 | 优先独立幅度规则的直接校准，收缩来源迁移主张 |
| C 好于 P，但与 C-rot 接近 | 自由度或一般子空间约束可能解释收益 | 不宣称真实 donor 结构独立有效 |
| C 只改善 fit，诊断和完整 Tail20 不改善 | 未获得可泛化收益 | 不以训练损失宣布路线二成功 |
| C 只在八步优于 P/F | 当前两步预算不支持该优势 | 单独评估更大预算是否值得；本轮不混比 |
| P/C/F 均未改善 N | 当前反馈事件协议没有产生实用增强 | 保留 A，停止基于这版反馈机制继续堆模块 |
| 确认 seed 的赢家不同 | 路线选择不稳定 | 保留不确定结论，不通过选 seed 强行定稿 |

“接近”按报告差值及预先登记的 delta 描述，不写成统计等效。若两者都比 F 差，即使 P 更便宜，也不能据此宣布来源增强成立。

## 8. 预算与执行顺序

1. 检查服务器事件材料；实现并通过公共坐标、投影、等价性和隔离检查。
2. seed42 同状态机制诊断与随机结构检查；有现成材料时补3407，材料不足不为短分支无条件重跑多条完整轨迹。
3. 数值检查通过后，seed42 完整 P/C/F 三组；N 复用。
4. 有来源候选值得继续时，固定 W，补 W-rot seed42，运行 P/C/F 在0和3407的六组。
5. 主张真实来源独立价值时补 W-rot 在0和3407的两组；N seed0 若缺失补一组。

核心主线完整训练：开发3组；继续确认最多新增6组；随机来源归因最多新增3组；缺失的 seed0 N 最多新增1组，即通常3组起步、有希望才扩到最多13组。若服务器事件全丢失、需要seed42参考采集，再加1条参考轨迹；M/S后续采用需另列预算。

旧AB/直接校准完整运行曾约14.4–16.2小时，只能作历史背景，不能据此承诺新组耗时。先测一条新运行的耗时与峰值显存；所有估算包含公共残差梯度通信，并单列预检、来源探测、随机对照和诊断成本。

## 9. 实现验收与交付文件

建议实现边界：低维公共坐标/投影数学模块；保存事件的通用加载器；独立同状态运行器；独立完整训练配置；按 seed 配对汇总器。运行器默认 plan/preflight，显式 run 才进入 GPU 训练。

必须检查：

- N 关闭分支行为与旧 A 一致；O 在旧清单上复现保存的更新。
- X 重建的有效 LoRA 输出与 sRA 相等，范数一致；小张量与真实模块各做数值比较。
- P/M 非负性、S/C 子空间成员资格、共同半径、NNLS KKT 条件；投影幂等性与嵌套可行性。
- C 子空间残差可以用真实 D_jl 与某组 C_jl 重建；不可只验证形状。
- 随机来源保持声明的几何量，且未同步旋转模型；rng与训练/数据增强相互隔离。
- 每个同状态分支前还原全部模型状态、模式和随机状态；只读取参考文件。
- fit/诊断按原图片ID无交叉；完整训练配对样本相同；不读取测试值控制训练。
- 每步只在全部客户端反馈完成后提交一次共享更新；A、基础B、来源在该事件优化中固定。
- 保存协议、源文件摘要、输入身份、完成回执；半轮中断从本次事件零初始化重新开始，禁止使用半训练C。
