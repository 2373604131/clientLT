新方法 A：必要判别余量保持＋主动分类学习（margin-keep-v1）
日期：2026-10-13

一、实现范围和独立性

独立入口：scripts/run_cliplora_method_a_margin.py。
独立实验臂：method_a_margin；独立算法/断点版本：margin-keep-v1。
本入口只运行新 A＋原 joint，不连接新 B、旧 B、共享 C 或 donor。
新 B 的 F-tail-equal 入口及旧 Full-CP、source-memory-v2 都保留各自行为。
现有新 B 入口目前使用旧 Full-CP＋FedAvg；不能把其结果与本入口直接相减，
声称是相同底座的 A/B 消融。将来的组合和 2×2 消融需另行固定相同底座。

用户已确认的探索默认值：
  epsilon=0.01，margin_scale=0.01，keep_weight=1，learn_weight=1。
  它们是正式运行前固定的探索配置，不是经测试精度选出的最优值。
  固定尺度改变了旧归一化，本版没有机械沿用旧保持系数 10。
  四个值写入 experiment_plan.json、命令、sfra_config.json 和 checkpoint。
  可以在新输出目录用命令参数显式设置；原目录内不得悄悄换参数或算法。

二、训练流程

第1—90轮：
  1. 固定 A，所有客户端正常训练 B 三个 epoch，按原 joint 聚合。
  2. 固定同一个聚合后的 B，客户端正常训练 A 一个 epoch，按 joint 聚合为 A_ord。
  3. 在 A_ord 上前向全部固定训练见证，计算保持缺口和分类损失。
  4. 有可靠历史且有缺口、半径非零时，执行恰好三步联合目标更新。
  5. 直接提交第三步；提交后的前向仅用于记录损失和更新可靠历史。
第91—100轮：A 及其历史不再更新，只正常训练 B。

不使用全幅/半幅候选，不使用 CE 或 J 验收，不根据损失、精度回退。
不做线搜索或用“最佳中间步”替代第三步。
没有历史、没有缺口或半径为零时不启动额外修正；这是启动条件。
启动后即使目标或某组 CE 上升，也直接提交第三步。
NaN/Inf 明确报错，中断的未提交轮次不更新历史；不把数值失败当作普通 A 回退。

三、历史和目标

沿用每个非空客户端—类别至多8张固定训练见证、标准视图＋固定水平翻转。
保护粒度为单张见证图，按稳定原始 sample_id 对齐，不使用测试样本。
间隔 m_iv = 未缩放正确类余弦分数 − 最强错误类余弦分数。

初始化两视图均严格为正时登记 H_i=min_v m_iv，否则历史无效。
之后只观察实际提交模型，在1—5、6—10等非重叠窗口取五轮双视图最小间隔。
候选严格为正，且旧历史无效或严格高于旧 H，才登记。
第5轮提交后登记的历史，第6轮才可使用；不增加0.001改善门槛。
每个窗口都观察全部见证，包括尚未学会的样本；否则无法登记新增能力。

保护底线 P_i=min(H_i, epsilon)，两个视图使用同一底线。
本轮修正中 P、有效掩码、权重、共享尺度均固定并停止梯度。
不恢复历史高置信度，不使用当前增强项，也不计算来源 pi/kappa。

设 q=(k,c)，固定见证数为 K_kc，每张见证代表质量 b_i=n_kc/K_kc。
在有有效历史的类别集合 C_hist 内，类别总权重相同：
  omega_i=(1/|C_hist|)*b_i/sum_{l属于类别c的有效历史} b_l。
无有效历史时保持损失为0，不做空集合归一化。
保持损失：
  L_keep=sum_i omega_i/4 * sum_v [max(P_i-m_iv,0)/margin_scale]^2。
先逐图 hinge，再求和；每次更新检查全部有效历史，包含原本没有缺口的样本。

四、主动分类和有限修正

分类 CE 使用全部固定见证及两视图，包含没有历史、当前答错的样本。
logits=exp(logit_scale)*cosine+原来的 LA 偏置；保持原先验和 tau。
三组内部为类平均，类内按本地训练样本数恢复权重：
  C_g=(1/|g|)*sum_c sum_k (n_kc/n_c)*(1/(2*K_kc))*sum_{i,v} CE_iv。
  C_label=0.2*C_Head20+0.6*C_Middle60+0.2*C_Tail20，即100类等权。
实现按组内类别数/总类别数计算系数，避免把类不等权的损失误称等权。
这些全局系数已含双视图和客户端份额，服务器直接求和，不重复乘聚合权重。

R=sqrt(mean_j ||delta_A_j||^2)，按全部 A 模块联合计算未加权客户端 RMS。
即使聚合更新互相抵消，只要本地 RMS 非零，仍允许启动修正。
A(z)=A_ord+R*z，||z||<=1。
J(z)=0.5*||z||^2+keep_weight*L_keep(A(z))+learn_weight*C_label(A(z))。
z0=0；步长0.1；固定三步，每步投影到一个全局单位球，直接提交 z3。
联合反馈返回已经包含两个系数的 grad_A；转换为 grad_z 时只乘一次 R。
B 和预训练主干在这段修正中固定。

保持和分类共用同一模型、同一批次的前向；联合标量只反传一次。
不为三个类别组分别反传，也不计算每个单元的完整梯度范数。
不计算 QR、来源响应、来源窗口或来源集中度，不保留“以后可能使用”的在线来源成本。
启动检查是一次无反向的 ordinary 前向；启动后有 z0/z1/z2 三次联合梯度遍历，
以及一次实际提交模型的无反向观察。无缺口时只有 ordinary 观察。
固定前缀缓存只复用冻结部分，模型可训练后缀读取当前共享 A/B。
反馈保持独立随机状态，不推进普通训练随机流。

五、独立运行命令

在仓库根目录，使用原训练 Python 环境。
仅登记配置（默认阶段，不启动训练）：
  python scripts/run_cliplora_method_a_margin.py --stage plan
文件、数据和配置预检（不宣称执行过 GPU）：
  python scripts/run_cliplora_method_a_margin.py --stage preflight

服务器 GPU 例子，先运行独立六轮 smoke，覆盖第5→6轮历史：
  CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=3 python -u scripts/run_cliplora_method_a_margin.py --stage smoke
通过后显式运行100轮（不会自动启动 B 或其他消融臂）：
  CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=3 python -u scripts/run_cliplora_method_a_margin.py --stage run
分段运行：
  CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=3 python -u scripts/run_cliplora_method_a_margin.py --stage run --stop-after-round 30
继续到100轮：重新执行同一个 --stage run，省略 --stop-after-round；自动恢复已提交整轮。
--stage smoke 在六轮完成后返回，绝不自动进入完整训练。

默认8个客户端并发；--client-concurrency 可显式指定1/4/6/8。
--num-workers 控制 DataLoader，不能当成客户端并发数。
默认固定 seed42、原 joint lambda=0.1、原划分、普通 A/B 学习预算和日程。
默认输出：output/cifar100_LT/method_a_margin_v1_joint。
训练目录：runs/seed42/method_a_margin；smoke 在 smoke/seed42/method_a_margin。
同一实验的 preflight/smoke/run 必须使用相同路径、参数和并发设置。

如果需要显式传入默认系数：
  python scripts/run_cliplora_method_a_margin.py --stage plan --epsilon 0.01 --margin-scale 0.01 --keep-weight 1 --learn-weight 1
本版参数要求有限正数；ordinary A 对照使用既有独立 plain-A 入口，不用零系数伪装。
代码版本固定到每次注册；正在运行的工作副本不应中途替换代码。

六、观察、汇总与消融

  python scripts/run_cliplora_method_a_margin.py --stage status
  python scripts/run_cliplora_method_a_margin.py --stage summary
  python scripts/run_cliplora_method_a_margin.py --stage pack
可用 --baseline-root 指向同 joint 的 ordinary A 实验根目录，目录内应有 experiment_plan.json 和 runs/seed42/plain_a。
缺失对照标为 unavailable，不自动补跑，不读取测试准确率来控制训练。
首要对照为新 A＋joint vs ordinary A＋joint；普通本地 SGD 预算相同，额外计算不同。
新 B 单独保留，本轮没有自动建立 A＋B 的组合路径或扩大实验矩阵。

sfra_rounds.csv：启动原因、固定更新步数、实际提交步数、历史登记、缺口数量、
  ordinary/final 的保持损失、分类损失、头中尾 CE、目标值及修正范数。
  没有 selected_beta、full/half 拒绝项或 CE 上界；损失变化只是记录。
sfra_costs.csv：各阶段实际前向图数、反向图数、联合反向次数、耗时与原通信估算口径。
checkpoint 同时保存已提交模型、历史和未完成五轮窗口、训练 RNG；不含来源窗口。
分析目录保存81—100轮均值、成本、逐样本学习/保持分解、同轮修正得失及可配对性。
20个连续轮次不视为20个独立重复，训练余量软目标不保证测试准确率不下降。

七、本地验证与边界

  python -m unittest tests.test_method_a_margin -v
测试覆盖：正历史与底线；类别/视图质量；联合梯度与半径链式法则；
没有历史的样本仍参与分类；缓存与真实小模型直接前向一致；
每批只做一次联合反向；缺口启动/无缺口不反传；损失上升仍直接提交第三步；
五轮窗口与第六轮启用；六轮小模型训练和中途恢复；第91轮冻结 A/历史；
独立入口与参数注册；结果核对不重新引入回退约束。
本机 PyTorch 为 CPU 版本，未执行真实 CIFAR100/30客户端 GPU smoke 或100轮实验。
本地小模型六轮测试不能替代上述服务器 smoke，也不能证明模型精度或加速收益。
