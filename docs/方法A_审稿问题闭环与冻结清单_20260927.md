# 方法A：审稿问题闭环与冻结清单

日期：2026-09-27。依据用户本轮明确范围：以所附技术意见中针对A的疑问为有限验收清单，完成后固定A，不因一般性能取舍不断改方法。

附件自身注明“模拟审稿判断”，本文件把它作为技术核查清单，不把其中的评分视为正式评审或录用预测。仅处理A及支撑A的论文论证；B的筛选、适配和协同收益不进入A的冻结条件。

## 当前决定

1. **现在固定开发版本。** 沿用[现有冻结规范](cliplora_method_a_full_cp.md)：Full-CP、λ10、μ1、当前与历史功能目标、来源优先级、三步修正及原提交规则。审稿验证中的消融是对照，不自动成为新的方法版本。
2. **暂停新增分类保护设计和超参数搜索。** 分组CP是可选研究候选，不是冻结A的必做项。用户没有要求通过本清单启动新训练，本次只整理验收条件。
3. **把“问题已回答”和“所有实验有利”区分开。** 允许准确率取舍和无独立增益的配套组件；已有反面或不确定结果必须保留。若核心来源主张被公平对照否定，不能仅以“已经回答”为由把该主张定稿。
4. **清单关闭后正式固定A。** 后续多seed、其他数据集和与B组合可继续验证；通常不重新搜索A配方。实际实现错误或足以推翻核心主张的新证据，需要单独登记后重新判断，不是一般指标没有全部上涨就解冻。

## 审稿风格与回应原则

依据“只去掉来源信息，结果会差多少”“这里至少需要区分”等具体问题，意见接近精准建设型、同时看重实验对照，判断置信度中等。按问题逐条给证据，比增加模块或承诺全面改善更合适。不使用审稿人群体统计推算本文录用概率。

每条按“问题→已有证据→未覆盖部分→最终论文中的表述”处理。公式定义能回答行为，实验才能回答收益；解释与补实验分开，避免把没有证据的核心主张仅改写措辞后继续保留。

## 六条短程实验带来的补充证据

“是否只是缩小更新”已经被实际检验，不能忽略其结果，也不能把它当作已证明完整等效：

- 完整A相对等幅度组，两个窗口五轮Tail均值差为0、+0.05点；Medium为−0.046、−0.154点。
- 末轮Tail各净多答对2/2000个样本，提示少量额外保持，但尚不足以宣布复杂方向稳健更优。
- 本项与A09共同约束“超出简单方法的价值”主张。若要主张完整训练收益超出简单弱化更新，需要预先固定的完整比较；不凭这两段五轮结果宣布全程胜出或失败。
- 它不替代来源对应、历史及普通保持对照，也不要求立即修改CP。

## 有限执行顺序

1. **先关闭不需要新训练的条目。** 整理损害与取舍、方法定义、现有样本/协议审计、来源强度统计及成本。检查服务器上是否已有Current-CP、初始/连续检查点及可复用对照，避免因为本地缺结果而重跑。
2. **只补核心缺口。** 来源优先级、打乱对应、同版历史和最相关普通保持对照。它们围绕A06—A09，不自动追加新模块、μ扫描、全拓扑网格或所有方法的多seed全集。
3. **对最终主方法和最有辨别力的对照做配对重复。** 配置、评估窗口、主指标和取舍口径在运行前固定。两个起点、轮次和类别不是独立seed；不得根据首批赢家改变需要重复的标准来掩盖不利结果。
4. **一次性判断。** 保留获支持的核心主张；配套组件如无独立贡献，降低其论文地位。若来源感知核心没有得到支持，明确决定收缩论文主张或简化方法，不以不断增加模块挽救预设结论。

本文件不自动启动以上训练，也不将“代码已实现”当成“实验已完成”。精确运行数量在回收已有结果、确定最相关简单对照后登记；该登记只填补本清单，不扩大问题范围。

## 正式冻结的停止条件

- 定义、实现与配置一致，无已知影响结论的实现错误。
- 凡保留为核心贡献的来源/历史/保持主张，都有直接、可比的证据；不受支持的非核心表述已删除或降级。
- 完整A相对相关简单方案的收益或学习—保持取舍，有足够可复核的支持；不要求所有列第一，也不设置事后挑选的“涨多少点就过关”阈值。
- 原有/新学能力的表述符合实际队列证据，来源集中与强度的解释没有混用。
- Overall、Medium、Tail及成本与局限同时公开，已有不利对照不被隐藏。
- 关键结果完成预定的配对重复，主张范围与验证范围一致。

满足这些条件后，A固定为论文方法，后续工作转向论文验证、写作及B的独立研究。一般局限、个别非主要指标下降或想继续提升分数，不自动成为修改A的理由。完成这份清单是停止设计A的依据，不是CVPR录用保证。
