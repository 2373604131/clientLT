# 方法A：seed42四组100轮补充实验结果分析

分析日期：2026-09-29。

**判断：这批结果支持保留A作为偏重尾类保持的固定研究基线。长程记录出现了超出等幅度缩步、普通功能保持的额外尾类收益，但中频类学习减少的代价仍在。历史目标的作用较清楚，类内来源权重精确对应的增量较小；CP没有被这四组单独证明为必要贡献。可以收束这一轮A设计，进入B的设计工作；“算法固定”不能写成“全部机制和泛化结论已经证实”。**

这是一份已完成结果的离线分析，没有新增训练、冒烟测试或哈希核验。原始服务器分析文件保持不变。

## 数据、完整性与比较边界

输入：`output/method_a_supplement_seed42_fast_v2_f128_c4_results/method_a_supplement_seed42_fast_v2_f128_c4`。本次另外接入本地原有普通更新S和第60/80轮的六个短程分支。

- 四组完成标记均为第100轮；每组都有第0—100轮共101份逐样本预测，每份10000个样本。
- 检查了样本ID、类别、预测对错及损失数值；预测重算的逐类准确率与保存结果一致，最大误差约`7.11e-15`个百分点。
- 四组的第0轮逐样本预测与导出的Full-CP初始化预测一致。Full-CP保存状态重新评估的9个轮次，与原结果的逐类准确率一致。
- 各组本地优化步数均为137280；三个修正对照均执行270次修正，Norm-Matched为0次修正。
- 同轮90次控制核验通过：Shuffle保留权重多重集合及每类总权重，Current不使用历史激活或历史目标，Plain-Hold为全功能均匀权重及`max(post-B margin, valid history)`，Norm-Matched匹配原Full-CP同轮有效更新幅度。
- 导出的服务器报告缺S和共同短程队列；本次已用本地既有数据补齐，六条短分支起点对错预测均与相应Full-CP参考一致，共生成90条分组、队列记录，无缺失。

**执行版本限制必须随结果一起报告：原Full-CP和S为普通执行版，新四组为fast-v2，Flat-CP为旧加速版。** 分区、已核对的训练配置和日程等一致，兼容性检查发现的差异是执行设置。初始化预测相同、参考模型重新评估相同，都不能证明100轮训练数值等价；历史更新和来源判定含阈值，也可能放大微小数值差别。因此以下跨执行版本差值是观察结果，不称为完全排除实现差异的严格消融因果效应。单seed和连续20轮不能提供跨seed稳定性证明。

## 原问题1：分类保护为什么没有保住中频收益

**证据一致指向：功能保持抵消了一部分普通A的学习收益；中频下降主要表现为少学会，而不是单纯多遗忘。**

先看同一轮普通提案与修正后模型的训练见证数据，以下为61—90轮平均，按类均衡、类内客户端—类别单位均衡计算。LA损失变化为“修正后减普通提案”，不是测试准确率百分点。

| 训练频数组 | 分类LA损失变化 | 普通A带来的平均margin增益 | 修正后保留的平均margin增益 |
|---|---:|---:|---:|
| Many35 | +0.001040 | +0.00002928 | +0.00001312 |
| Medium35 | +0.001287 | +0.00001025 | +0.00000398 |
| Few30 | −0.002212 | −0.00000271 | +0.00000071 |
| Tail20 | −0.002712 | +0.000000125 | +0.000000441 |

中频平均margin增益约61%在修正后被抵消。35个中频类中，16类的平均LA损失被修正提高，12类出现普通提案平均margin改善、修正后反而低于A更新前的现象。损害最大的前三类仍是42、45、67，与先前短程分析一致。第42类81—100轮平均准确率为Full-CP 33.65%、S 44.15%、Norm-Matched 40.25%。这是定位信息，不应据此把测试类别名单硬编码进训练保护规则。

CP优化的是样本加权总损失，61—90轮各组CP权重约为Many35 81.35%、Medium35 15.84%、Few30 2.81%，其中Tail20占1.41%。它不是每个频数组都不得受损的硬约束。Full-CP每轮修正后的总CP分类损失仍平均增加0.000875；功能项与激活的分类项梯度平均余弦为−0.879，冲突仍很强。

再看测试样本：以相同第0轮初始化划分中频类样本，第100轮：

| 方法 | 初始正确2256个中，最后仍正确 | 初始错误1244个中，最后变正确 |
|---|---:|---:|
| Full-CP | 2160 | 255 |
| Norm-Matched | 2158 | 281 |
| Plain-Hold | 2159 | 279 |
| Current-CP | 2160 | 301 |

Full相对Norm多保住2个初始正确样本，却少答对26个初始错误样本，净少24个中频正确样本。此表按共同初始化划分，描述的是完整轨迹的终点；“末轮变正确”不等于对每个样本都有连续稳定学习的证明。结合此前同起点短程分支中“少新增正确”的结果，足以回答中频代价具体表现在哪里。

**本次没有新增完整无CP对照，不能把这些差异单独归因于CP好坏。** 既有同状态μ0/μ1探针显示CP约缓解11%的中频训练LA损害，但没有清晰的中频、尾类准确率差异；这仍是局部证据。可以把CP保留为当前配方的取舍项，不宜单列“已经充分验证的必要贡献”，也没有依据继续单纯增大μ。

## 原问题2：是不是简单缩步就够了

**100轮记录比之前五轮窗口更支持额外尾类增量，但仍体现明确取舍。**

- Norm-Matched确实匹配了Full第1—90轮的有效LoRA更新范数，最大相对误差`2.85e-6`，即约0.000285%。这次比较不应以“没有匹配好”解释。
- 缩放系数平均0.615，最小0.378；有2轮略大于1，最大1.00000047，属于极小幅度偏差，实际如实记录未截断。该系数是Norm自身提案的缩放，不能与Full缩为自身提案37.7%的后期均值混为一谈。
- Full的Tail后20轮均值高0.9025点，回落1.00对2.10；但Medium低0.8371点，Overall低0.057点。
- 第100轮Tail为70.65%对69.55%，即Full净多答对22/2000个尾类样本；配对记录为Full独对27个、Norm独对5个。
- 以S为数值参照，缩步已有Tail增量1.37点，Full增量2.2725点，前者约为后者60%。这只是观察差值比例，不是把机制因果拆成“60%来自缩步”。

可用表述：“在此seed和已记录执行设置下，单纯匹配更新幅度未完全复现Full-CP的尾类保持，完整方向修正还伴随额外尾类收益，但牺牲了一部分中频学习。”

不应表述：“简单方法无效”“完整方法各项更优”“已排除所有缩步策略”。Norm借用了先跑Full的90轮幅度序列，是有参考依赖的诊断对照，不是一个已独立验证的固定小学习率算法。

## 另外三个机制问题

### 历史是否重要

Full对Current的Tail差2.00点，回落1.00对3.35。Current的逐轮记录确认历史没有激活任何单位或抬高目标；后期更新幅度仍为自身普通提案约92.3%，方向余弦约0.998，而Full约为37.7%和0.203。结果与“历史保持是主要保持来源”相符。

可以承认历史是关键支柱。不能把2.00点除以总增益当作历史的精确独立贡献比例，因为目标、权重、后续状态会互相影响；执行版本限制也仍存在。

### 来源信息和正确权重对应是否有用

Full比Plain-Hold的Tail高0.885点，比Flat高0.880点，伴随更小回落；提示完整来源构造有额外尾类价值。Plain-Hold与Flat几乎重合（Tail差0.005点），目前没有清晰证据说明“当前来源增益目标”本身很重要；两控制还有其他定义差异，不能据此单独量化这一项。

Shuffle逐轮平均改变99.61%的活跃权重，最少一轮也改变92.75%，并且保留每类权重总量及整体分布。不是一个几乎没打乱的无效对照。但Full对Shuffle只有Tail +0.305点、回落少0.20点，中频反而低0.264点；第100轮尾类仅净多答对5个样本（Full独对6个、Shuffle独对1个）。

因此，“类内正确对应带来小幅额外保持”有单次趋势，“来源精确识别是巨大且不可替代的核心优势”证据不足。Shuffle保留了来源构造目标及每类总权重，只打乱类内分配；它不能回答去掉全部来源信息的效果。上述实验也没有验证所有蒸馏或普通保持方法。

### 保住的是初始化已有能力，还是训练后学会的能力

已用第0轮和58—60/78—80三轮预测定义共同队列，合并原有同起点短分支。下表报告每个五轮窗口结束时仍正确的尾类样本数：

| 窗口 | 方法 | 初始化正确且起点前连续正确 | 初始化错误、起点前连续正确 |
|---|---|---:|---:|
| 60→65 | Full-CP | 1273 / 1274 | 156 / 157 |
| 60→65 | 普通更新 | 1269 / 1274 | 154 / 157 |
| 60→65 | 等幅度更新 | 1270 / 1274 | 156 / 157 |
| 80→85 | Full-CP | 1265 / 1268 | 154 / 157 |
| 80→85 | 普通更新 | 1258 / 1268 | 152 / 157 |
| 80→85 | 等幅度更新 | 1262 / 1268 | 155 / 157 |

相对普通更新，Full两个窗口均多保住了初始已有和训练后学会两类样本，因此不能把作用描述成“仅维持初始化能力”。但是相对等幅度缩步，Full的已学会队列一次持平、一次少保住1个，其新增保持优势主要出现在初始已有队列。样本差异小，不足以声称对新学能力有稳定的独立优势。

第0轮是相同任务评估配置下的初始化模型，虽然记录显示初始LoRA B为零，仍不自动替换为另一套评估定义下的“零样本CLIP能力”。队列保留也只是操作性行为定义，不是对知识来源的完整因果证明。

## 当前能固定什么、哪些结论仍要保留

| 问题 | 当前状态 | 合理结论 |
|---|---|---|
| 中频代价来自哪里 | 已有训练与测试证据 | 主要是学习收益减少，CP保护不完全 |
| 简单缩步是否解释全部 | 长程出现额外尾类增量 | 不能完全复现Full记录，但简单缩步已有很大一部分收益 |
| 普通功能保持是否够用 | Full有尾类增量及中频代价 | 支持取舍，不支持全面优越或胜过所有保持算法 |
| 历史是否重要 | 较强的单seed趋势及机制记录 | 历史是保持主线的重要支柱 |
| 正确类内来源对应是否必要 | 增量小，尚不能定论 | 只报告小幅趋势，不夸大贡献 |
| 初始与后学能力 | 共同短程队列已补齐 | 相对普通更新两类均有保持；相对缩步的新学优势不明确 |
| CP独立贡献 | 四组未单独识别 | 不写成已经证实的必要模块 |
| 严格同版消融及跨seed稳定性 | 仍有边界 | 不用单seed混执行记录声称已经完成 |

建议现在固定A算法定义和λ10、μ1参考配置，用它开展B的设计；本轮四组结果收束，不因取舍存在就追加模块或扫描参数。正文主张围绕“减轻尾类能力回落，并坦诚报告学习代价”，弱化尚未证实的细粒度来源归因及CP必要性。

如果后续要把跨版差值升级为严格配对消融结论，剩余技术缺口是Full参考与四组之间的执行一致性依据。现有记录不能消除它；一种直接办法是同版Full参考，但本报告没有启动或要求立刻追加训练。固定算法与补结论证据是两个决定。A+B效果、其他seed和更广泛任务不由本次A实验直接推出。
