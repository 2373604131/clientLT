# 方法A：五项疑问的最小完整实验设计

日期：2026-09-28。范围仅为用户选中的五项：来源优先级、正确来源对应、历史保持、普通保持/简单缩步、原有与新学能力。沿用[冻结清单](方法A_审稿问题闭环与冻结清单_20260927.md)，不改A主方法，不扩展B或新的拓扑研究。本文件是设计，不代表已启动或已完成新实验。

## 数量先说清楚

- 一张完整对照表包含 **7种配置**，每种从相同初始化训练100轮；同一seed下为7次训练。
- 其中Full-CP及5种针对性对照共6种，另保留普通更新S作共同基线。S不会因为被不同问题引用而重复训练。
- seed42已经有S、Full-CP μ1和Flat-CP结果。**只有通过可比性核对才复用**；三者全可复用时，新增训练为4次：Shuffle-CP、Current-CP、Plain-Hold、Norm-Matched-100。
- 如果服务器已有合格Current-CP，新增量可进一步降为3次；本地目前未核实到该完整结果。旧Current无CP不能替代。
- 如果旧配置不能合法复用，新增量按“7减已验证可复用配置数”计算。特别是已有Full-CP与Flat-CP执行版本不同，不能提前承诺只需要4次新训练。
- “原有/新学能力”是附加评估任务，**新增0条训练**，前提是服务器保留相应模型状态。缺模型先盘点，不能从总体准确率恢复逐样本历史。
- 若所有7种配置使用3个配对训练seed，总计21次100轮训练；不是21种方法。已有seed42的3次全可复用时，剩余18次。3个seed是本方案建议的重复规模，不是CVPR硬性要求，也不保证统计显著或录用。

第一阶段先凑齐seed42的7种配置并完成原始记录核查；它能给出单seed机制证据，不能单独承诺跨seed稳定。后续重复的配置范围和统计口径应在看新增结果前登记，避免只重复有利的对照。

## 七种配置及唯一用途

| 编号 | 配置名称 | 运行内容 | 核心比较 |
|---|---|---|---|
| E0 | S：普通更新 | 每轮普通B训练，前90轮普通A学习与聚合，直接提交提案 | 提供总体学习/遗忘基准 |
| E1 | Full-CP：完整A | 冻结的λ10、μ1、来源优先级、当前/历史目标、三步修正 | 所有问题共用的主方法 |
| E2 | Flat-CP | 保留来源构造的当前目标、历史、CP及修正，仅把活跃功能权重统一 | E1−E2：来源优先级的条件作用 |
| E3 | Shuffle-CP | 保留当前目标、历史和CP，把原先给某功能的来源权重改配给其他功能 | E1−E3：正确对应的价值 |
| E4 | Current-CP | 保留来源优先级、CP和修正，仅去掉历史目标及其激活作用 | E1−E4：历史的条件作用 |
| E5 | Plain-Hold | 不计算来源权重，不用来源响应提高当前目标；以均匀功能权重保持更新前及历史已有的margin，保留同形式修正与CP | E1−E5：整个来源感知方案相对普通功能保持的价值 |
| E6 | Norm-Matched-100 | 普通A方向，所有层共用一个标量；每轮实际有效LoRA更新范数匹配E1同轮记录 | E1−E6：全程幅度相近时，复杂修正方向的增量价值 |

Flat-CP的当前目标仍含来源信息，因此它不能兼作Plain-Hold；等幅度普通更新没有保持目标，也不能兼作Plain-Hold。为覆盖用户明确提出的这两个替代解释，本方案保留E5和E6各一组，不以其中一个冒充另一个。

这7种配置是本次针对性设计，不是所有研究问题都适用的数学最小值。若缩小核心主张，可以减少对照，但必须同时缩小可回答的问题。

## 对照的关键定义

### E3：打乱对应，保持比较可解释

默认采用**同一类别内部的客户端—类别功能单位之间打乱**：保留整体权重分布及每类总权重，改变同类不同客户端功能拿到的权重。这样可检查“正确的细粒度对应”是否超出类别总体调权。

- 使用该分支当轮本应产生的权重值；不复制另一训练轨迹上的目标、历史或权重。
- 打乱仅作用于当轮活跃单位，不把有效权重分给无目标单位。
- 训练开始前固定独立的打乱随机规则，不按测试表现挑映射；不消耗本地训练随机流。映射尽量固定，活跃集合变化时按同一规则重建，不人为增加逐轮随机抖动。
- 保留来源构造的当前目标、历史、归一化、CP、修正步数和半径规则。
- 记录可交换单位数量、实际改变权重的单位比例、每类权重总量和有效更新范数。某类只有一个活跃单位时不能打乱，需如实记录。

该对照回答的是类内细粒度对应；若它无收益，不能宣称类内对应有用。它也不是“去掉全部来源信息”。不在看到结果后另换全局打乱以追求有利结论；若未来更换，应作为新的独立设计登记。

### E5：普通功能保持的具体定义

在本轮普通B聚合之后、A更新之前，记录每个功能的margin `F_preA`；历史有效时记为 `H`。普通保持目标为：

`T = max(F_preA, H)`，历史无效时 `T = F_preA`。

用活跃功能均匀权重，惩罚候选模型低于该目标的部分。它只保住更新前或历史上已有的水平，不使用来源响应产生额外增强量。历史登记规则与完整A相同，历史只用本分支实际提交模型更新；测试预测不进入目标。

保留同一个普通A提案、修正变量、半径规则、功能尺度定义、λ10、μ1及三步更新，便于比较。若功能尺度需梯度范数，仍需计算并计入开销；“不使用来源”不等于没有反馈成本。

这是自定义的同底座普通功能保持控制，不冒称某篇蒸馏算法的原版实现，也不据此声称战胜所有蒸馏方法。同一归一化/λ并不证明任何方法超参数最优；禁止依据最终测试集挑参数。

### E6：把已完成短程等幅度对照扩展到完整轨迹

- E1先训练或复用已通过核查的完整记录，取第1—90轮的实际有效更新范数序列；该序列来自训练，不来自测试表现。
- E6从与E1相同的初始模型出发，每轮在自己的状态上正常训练B、产生普通A提案，再整体缩放A增量，使所有层合并后的 `||s B ΔA||` 匹配E1同轮值。
- 只有幅度序列来自E1，后续B、普通提案、梯度和数据训练均属于E6自身轨迹，不每轮复制E1模型。
- 第91—100轮沿用共同B-only安排，不额外更新A。
- 记录缩放系数、目标/实际范数和误差；若某轮系数大于1，标记放大，不能偷偷截断；普通提案为零而目标非零时报告无法匹配。

它是幅度匹配诊断控制，运行成本包括获取E1幅度的依赖，不能宣传为独立低成本算法。即使两者接近，也不能宣称某个固定学习率必然全程等效；若要发布独立固定缩步算法，需另行设计，未计入本轮。

## 五个问题怎样由同一张表回答

| 用户问题 | 所需结果 | 支持什么；不支持什么 |
|---|---|---|
| 来源信息真的有用吗？ | E1对E2和E5 | 分别检查来源优先级，以及整体来源感知构造相对普通保持的收益；不能只用E1对S就归因来源 |
| 正确来源对应有用吗？ | E1对E3 | 正确类内权重分配是否提供收益；不能仅因权重不同就宣布有效 |
| 是不是主要靠历史保持？ | E1对E4，同时结合E2/E3/E5 | 历史移除影响、来源增量分开看；不要求来源贡献一定大于历史，也不把消融差值相加 |
| 普通保持或简单缩步够不够？ | E1对E5、E6，E0作共同参照 | 根据预定后期水平、保持、学习收益及成本判断额外价值，允许取舍，不要求所有指标领先 |
| 保住旧能力还是后来学会的？ | 初始/起点前连续模型预测，加已有短程各分支预测 | 同一起点、同一批样本比较旧能力与新学能力的保留；不增加方法训练配置 |

所有胜负均如实报告；不能保证这张表必然支持当前设计。若核心来源主张不受支持，按冻结清单收缩主张或简化方法，不追加模块反复追逐有利结果。

## 第五项：复用模型的评估方案

已有Full-CP第60、80轮预测，以及三条对应短程分支第65、85轮预测。优先在服务器补以下正式模型的预测：

**第0、58、59、78、79轮。** 第60/80轮预测复用现有结果，先核验样本ID和模型身份。

在每个起点分别预先固定两个队列：

1. **初始已有且起点前稳定会：** 第0轮预测正确，且58—60轮（或78—80轮）连续正确。
2. **训练后稳定学会：** 第0轮预测错误，且同一连续窗口三轮均正确。

两队列均由干预前记录定义，不能根据65/85轮结果选样本。对已有Full-CP、普通、等幅度三条分支，用完全相同的队列统计末轮正确保留、正确转错和各队列规模，另报不属于这两组的样本。这样可在不新训练的情况下区分能力来源。

第0轮必须是相同任务评估配置下的原始初始化模型；如果它与所称零样本CLIP不等价，报告“初始化已有能力”，不得改名为CLIP零样本能力。

这回答两个既有短程窗口内的来源分解。新增100轮运行同时保存第0轮及每轮固定样本预测，可补完整轨迹描述；各算法自行学会的样本集合可能不同，不能把不同队列的保留率冒充同一批样本的因果比较。无需为记录预测额外增加训练分支。

服务器若缺58/59/78/79轮状态，先查事件/提交权重能否恢复；不能把只有一个起点模型的预测等同连续稳定学会。必要时将该分析随新增运行记录，明确没有补齐旧共同队列。

## 统一实验与复用规则

- Client-LT、protocol seed42、相同实际训练样本及客户端划分、日程、初始化、见证和本地训练预算。
- 普通B训练保持3个本地epoch；A第1—90轮每轮1个本地epoch；第91—100轮只训练B。B迁移模块关闭。
- rank4、FP32、LA及其余训练参数沿用冻结配置。同一seed内使用相同配对随机协议；诊断前向及打乱不扰动训练RNG。
- 修正组使用相同执行版本及原三步规则。E0/E6没有功能修正，不人为给它们塞无用梯度步骤来伪装等成本；明确报告真实成本。E5/E1按反馈/修正预算与数据口径比较，来源测量额外成本单列。
- 主指标预定为81—100轮Overall、Medium35、Tail20均值；另报每轮曲线、末轮值、90→100变化、样本学习与保持和成本。峰值回落仅辅助，不挑最佳测试轮。
- 对新运行保存每轮逐样本预测及身份；评估不能反向选择功能目标、打乱映射、权重或缩放系数。
- 旧结果复用需核对上述项目；代码摘要不同不自动证明算法不同，但未审清的行为差异也不能当作相同。若执行版本不同，需有足够数值等价和协议依据；否则作为历史参考，不混进严格配对差值。
- 旧六条短程分支不能充当新的完整100轮结果；旧Current无CP、旧Full无CP也不能代替相应μ1配置。

## 实现与预算边界

现有正文入口提供S、Full-CP、Flat-CP、Current-CP以及无CP Full。2026-09-28已为四组新增独立100轮入口`scripts/run_method_a_supplement.py`，见[实现、启动与静态审查](方法A_四组100轮实现与启动_20260928.md)。按用户本次明确要求，不执行冒烟或短程测试，也不增加哈希验证，只做静态审查与语法检查；正式运行直接100轮。已有`run_method_a_diagnostics.py`的两起点五轮模式不作为该100轮入口。

本轮不新增无CP长实验、μ/λ扫描、多拓扑、多数据集、B实验或因果集中度网格。正式论文的外部方法覆盖与更广泛泛化另行规划，不把这张七组表称为完成整篇CVPR论文的全部证据。

完成第一阶段后，按同一预定评价口径决定哪些核心主张有支持；不因单seed表漂亮就省掉计划中的关键重复，也不因不利结果就改算法后混报同一方法。
