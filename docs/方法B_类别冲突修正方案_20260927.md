# 方法B：类别冲突的修正方案

日期：2026-09-27。状态：基于现有实现与结果的候选方案；后续独立实现已完成CPU检查，尚无新方案的正式训练结果。

后续实验协议见[问题2实验设计](方法B_问题2实验设计_20260927.md)：先确认共享C后的实际作用，再以单事件2×2对照分别检验类别汇总与损害反馈。下文三组嵌套比较为初始建议，具体执行以新协议为准。

代码进展与命令见[问题2运行说明](cliplora_b_problem2.md)。

## 1. 要修正的具体问题

现有筛选先用“任意一个符合缺类条件的目标尾类收益为正”接受一个 donor，再对所有接收端接受的 donor 取并集。已完成的共享B实验中，8次并集均覆盖全部30个客户端。

逐类探测确实发现了有益关系，也发现了冲突；问题出在这些关系被压缩成客户端是否入池，随后未继续约束来源使用。3361条通过筛选的“轮次—接收端—donor”记录中，1844条在已记录、符合缺类条件的目标类别上同时存在正负收益。这些是重复轮次的探测记录，不是3361个独立客户端，也不是最终模型的准确率结论。

此外，原始 donor 的单独探测收益不能直接代表经过完整矩阵C变换、与其他 donor 组合后的收益。不能仅凭原始负收益永久排除一个可经重组利用的来源。

## 2. 推荐的第一版：逐类反馈指导同一个共享更新

保留每个 donor、每个模块的完整矩阵C，以及现有残差形式：

`R(C) = mean_j(ΔB_j @ C_j)`

所有接收端都评估并优化同一个 `B_bar + R(C)`。普通FedAvg得到的当轮 `B_bar` 是参照模型，C=0对应不增加迁移残差。A、原始donor更新与基础B在校准过程中固定，最终仍只注入一次共享残差。

优先改变两件事：反馈如何汇总，以及怎样对待被迁移损害的类别。第一版固定全部当轮可用donor作为来源库；取消正收益并集对入池的决定作用，逐类探测可保留为诊断。对于当前已完成实验，这与原并集的成员相同；其他运行未必相同，不能直接声称所有配置都等价。

这版应表述为“利用目标类别反馈重组跨客户端知识”，不能继续声称其共享更新只使用了目标缺类且正收益的来源。缺类关系仍可用于机制分析；是否需要让来源选择成为独立模块，留给后续实验证据决定。

### 2.1 按类别组织反馈

对校准批次中每个“接收端k—类别c”，计算类别平均LA损失 `ell[k,c](C)`。

在尾类和非尾类各自内部，先对同一类别在不同反馈客户端上的损失求平均，再对当前反馈覆盖的类别求平均；最后按固定的尾/非尾组权重汇总。具体权重由预先生成的采样清单决定，不依赖损失大小或测试结果。缺失类别不填0、不假装已被评估，记录实际覆盖。

这样的目标是反馈所覆盖类别上的宏平均代理，不是全部客户端、全部类别总体风险的无偏估计。非尾类别轮换有助于扩大覆盖，但无法保证小批次或现有接收端包含所有非尾类。

与原版“每个客户端等权、客户端内部尾/非尾分组均值”相比，这是一项独立的目标权重变更，必须单独比较。并不预先保证类别宏平均优于原目标。

### 2.2 对受损类别增加软惩罚

在完全相同的校准图片上，保存迁移前C=0时的类别损失，并停止该参照值的梯度：

`harm[k,c](C) = max(0, ell[k,c](C) - stopgrad(ell[k,c](0)))`

每个接收端、每个类别先单独计算harm，再按上述类别权重汇总。不能先把不同类别的损失变化平均，再取正部，否则正负变化又会相互抵消。

建议验证的目标为：

`J(C) = L_class(C) + beta * H_class(C) + lambda_C * Reg(C)`

- `L_class`：按类别组织的尾/非尾分类损失，固定两组之间的权重。
- `H_class`：尾类与有反馈的非尾类上的逐类损害，采用一致的汇总规则。
- `Reg(C)`：保留现有C正则及其归一化，避免同时改变更新尺度控制。
- `beta`：新增损害项的权重；先用0与一个预先固定的正值验证机制，不同时进行多维扫描，也不把试验值称为最优值。

原版共享C的分类损失已经会对有益和有害变化作权衡。新增项的作用是让受损类别得到额外关注，减少“其他类别改善掩盖某些类别明显受损”的情况，并非原版完全没有利用负面反馈。

这是软惩罚，允许收益与代价之间的取舍，不承诺每类都改善，也不保证校准损失改善就转化为测试精度提升。B的参照是当轮迁移前模型；其目的仍是增加有效补充知识并控制当次负迁移，不替代A的历史知识保持任务。

### 2.3 基线、采样和两步优化必须对齐

现有两步优化使用两批不同的校准样本。每步的类别损害必须与C=0在该步同一批图片上的损失比较，不能拿第一批的迁移前损失减第二批的迁移后损失。

C从0初始化时，该正部损害项为0；使用通常的ReLU零点导数时，第一步没有新增损害梯度，第二步才有机会进行修正。因此不能声称原有两步一定足够。先保持两步做可比实验，并记录C=0、第一步后、第二步后的固定样本逐类损失；若轨迹表明优化未稳定，再单独检查学习率或步数，并给对照相同预算。

校准和损害参照都来自训练侧。现有校准与探测允许样本重叠，相关诊断不构成独立泛化证据；有足够样本时可另设不参与优化的训练侧诊断样本。测试集只用于统一评价，不控制donor选择或当轮更新。

## 3. 最小实验顺序

### 第一步：确认冗余筛选的等价性

在同一轮、相同模型状态、相同原始donor更新、相同采样和优化配置下，对比：

1. 原正收益筛选的并集 + 原共享C。
2. 全部当轮donor + 原共享C。

对于已记录的8个全覆盖候选池，两者的来源成员和共享C目标相同，预期得到相同更新，筛选耗时和通信统计可以不同。先核对成员、顺序、随机数隔离和一次输出等价性，不必为这个判断先重跑两个100轮实验。

复现单轮更新需要真实的模型状态和原始donor更新，仅凭donor_scores.csv或最终matrices.npz不足以重建。如果本地无完整状态，在下一次训练保存一个完整事件快照即可；不能把日志分析称为已经完成的等价性实验。

### 第二步：只比较目标函数的必要变化

| 配置 | 来源库与C | 校准目标 | 回答的问题 |
| --- | --- | --- | --- |
| B0 | 同一来源库、共享完整C | 原客户端分组均值 | 可比基线 |
| B1 | 同上 | 按类别组织反馈 | 类别权重是否影响迁移收益与代价 |
| B2 | 同上 | B1 + 逐类损害软惩罚 | 显式关注受损类别是否改善取舍 |

三者使用相同校准清单、普通训练协议和校准预算。第一轮可固定现有非尾类别轮换采样、尾/非尾组权重0.5，避免同时扫描0.5/0.35/0.2。此处B0/B1/B2是本方案的对照名称，与既有tradeoff文档的B1/B2/B3命名不同，正式实现时应使用明确的配置名区分。

旧的随机非尾采样结果可作背景对照，但不能单独承担新目标函数的公平基线。新采样本身的收益应与目标变化分开解释。

### 第三步：先确认机制，再检查完整训练结果

单次事件诊断记录：逐类LA变化、改善和受损的接收端—类别比例、损害总量与最大损害、固定样本上的总目标轨迹、实际LoRA残差相对普通更新的范数。比例和损害量都报告，因为许多微小改善不能抵消少数大幅受损。

正式效果统一报告81—100轮的Overall、Tail20、Few30和其余分组，包括Medium35；额外时间与通信也要记录。先在一致协议下完成机制比较，再对有希望的配置作配对多种子验证。单轮改善只能支持局部机制，不能替代100轮训练结果。

若新方案只是显著缩小残差，同时降低收益和损害，需要做残差幅度匹配的对照，才能判断收益是否来自类别反馈。此对照只在该疑点实际出现时补充。

## 4. 暂不推荐的改法

- 只把gain阈值从0提高：可能减少入选，但没有解决按类关系合并和实际组合效果变化的问题。
- 要求一个donor对所有类别、所有接收端都有效：可能排除可经重组利用的互补来源。
- 每个接收端只看自己的donor组合训练C，然后直接合并：各方评估的模型与最终共享模型不同，不能据此推断共享效果。
- 在没有反馈或用同一批样本挑选出来的“好结果”上声称保护了所有类别。
- 同时改变来源筛选、采样、尾组权重、学习率、步数与C结构，导致收益来源无法判断。

## 5. 是否保留donor筛选模块的决策

若共享C加逐类反馈已经改善尾类收益与其他类别代价，优先采用更简洁的方案，将正收益探测作为分析工具，删去无法证明价值的筛选贡献表述。

若还需要减少来源或证明选择模块的独立价值，再研究真正改变共享来源使用的全局选择：同时考虑各类的正收益、负收益幅度和覆盖，始终在同一个共享候选上重新评估。单独测试该模块相对全部来源是否有额外收益或更低成本，不预先把它写成已成立的方法贡献。
