# 三个 Insight 图包

这组图落实了本次修改后的三个研究发现：数据分给谁会影响结果；已有尾类能力会在后续训练中回落；永久冻结不是唯一选择，更新策略决定学习与保持的表现。

先打开 [图册](index.html)。`zh/` 是中文汇报版，`en/` 是英文论文版。每张均提供 300 dpi PNG、矢量 PDF 和保留文字对象的 SVG；SVG 在其他电脑上打开时需要相应字体，PDF 已嵌入字体。论文插图优先使用 PDF，PPT 可使用 PNG 或 SVG。

| 文件名 | 内容与用途 |
|---|---|
| `00_three_insights` | 三联总览，作为 Figure 1 候选：共同类别直方图及两种真实热图 → S 的真实轨迹 → E2/E3/S/J 的 Non-tail–Tail 散点图 |
| `01_client_distribution` | Insight 1：共同类别数量、同一 S 策略的尾类结果、两种类别×客户端热图 |
| `02_tail_forgetting` | Insight 2：S 和 J 两组原始训练曲线，以及两种划分各自的峰后回落 |
| `03_adaptation_and_retention` | Insight 3：左侧末20轮准确率，右侧尾类峰值与最终值；E3 相对 E2 的双向改善清楚可见 |
| `04_per_class_drop_supplement` | 补充图：20 个尾类分别计算峰后回落，避免只看组平均曲线 |

## 本次采纳的关键修改

1. 第一张展示真正的“类别×客户端”关系，替代只看每个客户端的尾类总数。两种划分均为同一批 10,847 张图片，各类样本数完全相同；Tail20 总计 153 张。标准 Dirichlet 为 `noniid-labeldir-fine`，β=0.5，未混入旧 matched-Dirichlet。
2. 第二张从第0轮初始化开始画到第100轮，使用“已有能力”的表述。S 的第91–100轮仅训练 B，已标出。没有平滑曲线，没有生成模型绘制的数值，也没有虚构误差带。
3. 第三张把 E3 纳入核心证据。E3 相对 E2：Non-tail +1.529375 pp，Tail +1.605 pp，Overall +1.5445 pp；这说明在当前设置下，适当开放 A 可以改善两组准确率。E3 的峰后回落为0.35 pp，E2为0.05 pp，图中完整保留，未声称E3的回落更小。
4. 研究发现与方法有效性分开。没有把 Full-CP 的成绩用于反向证明动机，没有把来源集中度与遗忘的联系画成已证实机制。来源加权、历史目标、CP 和 B 迁移的验证应另放在方法实验中。
5. 补充逐类回落分布。每个点是一个类别，不是一个独立种子；这一分布不能当作多种子误差条。

## 统计口径与限制

- 数据集：CIFAR100-LT；30客户端全参与；CLIP ViT-B/16 + LoRA；seed42；固定任务、固定类别集合；相关主图均使用 LA（logit adjustment，类别频率校正）。
- Tail20：训练数量最低的20类，当前类别编号80–99；Non-tail80：其余80类，不能称为Head20。保持本次讨论采用的20/60/20划分口径，未切换到 many/medium/few 阈值口径。
- 准确率：第81–100轮均值。回落：第1–100轮峰值减第100轮。原始 epoch 为 round−1。
- 逐类回落：每一类单独取第1–100轮峰值减最终值。其均值与“尾类组平均曲线的峰值减最终值”不同，前者也会对短期波动敏感；补充图作为描述性诊断，不自动证明每个类别持续遗忘。
- 第一张的两种划分同时改变了客户端容量、类别覆盖与本地组合，不能把全部差异归因于某一个支持来源指标。数据热图表示标签分配，不表示谁的更新具有有效功能帮助。
- E2：固定 LoRA 因子 A，日常训练 B，另有9次额外B更新。E3：日常 B，另有9次额外A更新。S：日常 B，前90轮各有一次额外A更新。J：日常 A/B 联训，另有9次额外A更新。
- Client-LT 的 E2/E3/J 各有108,768次本地优化步，S 有137,280次；标准Dirichlet对应为109,386与138,060次。相同步数也不等于严格相同FLOPs。新旧实验还存在代码版本差异，因此这里是完整策略的描述性比较，不是纯刷新频率的等预算因果消融。
- 当前都是单种子结果，不宣称统计显著性。没有把冻结 A 描述为必然防止后续所有遗忘。

## 数据与复现

`make_insights.py` 根据 `presentation/results_table_20260920/完整结果_长表.csv` 中的源目录定位8组实验，从808份逐类CSV重算全部指标，并核对原始逐轮CSV与现有大表。两种划分的样本ID–标签集合直接比较；每种划分内部四种策略的 manifest 和参与日程也直接比较。

`data/` 保留全部作图数据快照，`validation.json` 保留原始路径、SHA-256及数值核对结果。已用 `--from-snapshot` 独立重绘，10张PNG与原始文件模式生成的图片逐字节一致；快照模式排版检查保存在 `validation_snapshot.json`。训练文件未被修改，也没有重新训练。

在仓库根目录从原始文件重建：

```powershell
python presentation/insights_20260925/make_insights.py
```

解压图包后，也可以仅用随包CSV重绘：

```powershell
python make_insights.py --from-snapshot
```

依赖：Python、NumPy、Pandas、Matplotlib。样式在 `plot_utils.py` 中统一调整；默认英文 Arial，中文 Microsoft YaHei。数值标注由数据计算，显示采用四舍五入。
