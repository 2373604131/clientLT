## 重画全部图片

```bash
python output/la_control_ablation_analysis/presentation/make_closure_figures.py
```

只读取已有CSV，生成本目录图片与源数据表；不加载模型、不启动实验。脚本使用Microsoft YaHei显示中文。

- 正式拓扑比较仅普通Dir，不混入matched。
