# 方法 B 的 positive / zero 结果分析

日期：2026-09-30。

**结论：新版 B 相对 A-only 有小幅尾类提升，但本次实验没有充分证明正响应监督的额外价值，暂不宜把 positive 固定为最终方法。来源筛选和响应目标的接线已核对通过；当前瓶颈更集中在如何让这些目标真正影响共享 C 的优化。**

分析输入为 `output/sfra_b_response_analysis/sfra_b_response`，并重新读取已有 A-only、旧共享 B、三组轮换采样 B 和上一版 directed 的原始结果。只进行已有 CSV/JSON/NPZ 的离线复算，没有加载模型、重放训练、追加实验或修改训练实现。

复现命令：`python scripts/analyze_b_response_results.py`。脚本输出本目录中的证据表和 `audit.json`；本报告是对这些数据的解释。

**1. 两组完整运行，主要指标没有被末轮结果替代**

positive、zero 均完成100轮，保存完整的第0—100轮评估；分别进行8次 B 迁移、16次 C 优化。主指标仍是固定 Tail20 在第81—100轮提交模型上的测试准确率均值。精度单位为 %，差值单位为百分点。

| 方法 | 最后20轮 Tail20 | 相对 A-only | 第100轮 Tail20 | 最后20轮 Overall |
|---|---:|---:|---:|---:|
| A-only | 70.9350 | — | 70.65 | 70.6330 |
| 旧共享 B | 71.0875 | +0.1525 | 70.80 | 70.7025 |
| 轮换采样 B，w=0.5 | 71.1350 | +0.2000 | 70.90 | 70.7065 |
| 轮换采样 B，w=0.35 | 71.1575 | +0.2225 | 71.00 | 70.6965 |
| 轮换采样 B，w=0.2 | 71.1100 | +0.1750 | 71.05 | 70.6920 |
| 上一版 directed | 70.9150 | −0.0200 | 70.85 | 70.6475 |
| **本次 positive** | **71.0150** | **+0.0800** | **71.00** | **70.6055** |
| **本次 zero** | **71.0000** | **+0.0650** | **70.85** | **70.6015** |

positive 相对 zero 仅高 **0.0150** 个百分点；比旧共享 B 低0.0725，比历史 w=0.35 低0.1425。这些均为 seed42 的观测差异，不能据此声称显著提升、等效或显著退化。历史版本同时改变了反馈范围、视图、筛选准则和参数化，不能把版本间差异归因于某一个组件。

第100轮 positive 比 zero 高0.15，但这不是预设主指标。在最后20轮中，两组 Tail20 有16轮相同，4轮 positive 更高；20个尾类的最后20轮均值有16类相同，另外4类仅相差0.05—0.10。当前差异很有限，不能用单个末轮或少数类别放大结论。这里的轮次和类别都是同次训练的重复观测，不作为独立随机种子做显著性检验。

Overall 的小幅下降如实保留，但本报告的暂不固定判断依据是尾类增益和机制证据，不要求 B 独自承担 Overall 改善。

证据：`performance.csv`、`tail_curves.csv`、`tail_class_comparison.csv`。

**2. 筛选确实找到缺少目标标签的外部来源**

从划分文件重算客户端类别计数，再核对每次事件的来源列表、权重、教师 logits 和矩阵索引：

- 反馈只来自协议目标客户端27、28、29中的119张尾类训练图片，覆盖20类，每类4—9张；没有混入非尾类监督。
- 每次有506条合格的“目标类别—外部缺类 donor”候选，positive 中209—219条有正的双视图筛选增益。
- 每次20类均选到3个正来源，共60条关系；选中 donor 均在目标组外，实际本地数据确实没有对应目标类别标签。
- 每类 Top-3 和正增益归一化权重与保存的记录一致；选中教师的双视图筛选分数可以从保存的 logits 复算。
- positive 每次最终并集为22—26个 donor，每个 donor、每个 LoRA 模块都有独立 C，合计2112—2496个参数。
- 逐类关系同时进入正响应目标；positive 保存的是非零教学增量，zero 的实际教学增量严格为零，两组使用相同的实际正响应可用性规则和两步预算。

因此，本次证据不支持“没有找到有帮助的 donor”或“代码把 positive 跑成了 zero”的解释。并集较大也不能单独说明筛选失效：并集承担 C 参数基底，逐类来源关系另行决定教师目标。

但这项核验只证明训练侧资格、筛选及接线正确，不证明这些来源在测试上有不可替代的作用。两组都保留筛选，positive/zero 本身也无法单独证明该筛选优于无筛选或其他来源规则。这里的“缺标签”仅指 donor 的本地训练数据，不指其共享模型或预训练模型从未接触该类。

证据：`source_weights.csv`、`selected_gain_stats.csv`、`checks.csv`，以及原包各事件的 `response_targets.npz`、`matrices.npz`。

**3. 总目标下降，并不代表正响应目标学得更好**

C 的目标由尾类 LA、正响应误差和矩阵正则相加。对保存的 logits 独立复算后，positive 的8次事件均表现为：总目标下降、尾类平均 LA 下降，但正响应误差上升。

| positive 的训练侧指标 | 8次事件汇总 |
|---|---:|
| 优化前正响应误差，事件均值 | 0.00011609 |
| 优化后正响应误差，事件均值 | 0.00036879 |
| 正响应误差上升的事件 | 8/8 |
| 总目标下降的事件 | 8/8 |
| 两视图类等权 LA 平均改善 | 0.016156 |
| LA 改善 / 受损的事件—类别数 | 135 / 25 |

以第30轮为例，总目标从2.639616降至2.627455；与此同时，正响应误差从0.00008861升至0.00036666。说明当前加权和允许用 LA 的改善交换响应误差的恶化。

这个上升并不只是原本没有正增量的竞争关系被破坏所致：优化后的平均误差中，约0.00035545来自原本正增量的关系，约0.00001333来自零增量关系。也就是说，原本希望从 donor 学到的那些正向目标，其加权平方缺口整体也扩大了。

这不等于每个目标都变差。部分目标被超过，另一些目标受到更大损害；平方损失的大小和目标达成数量不能互相替代。共享 C 的优化仍允许样本、类别和竞争关系之间发生取舍。

证据：`objective_trace.csv`、`events.csv`、`class_changes.csv`。

**4. zero 已经实现了几乎同样的正响应达成率**

对 zero 也保留置零前的真实 donor 正响应，事后检查学生是否达到它。此项诊断不参与训练或选择。

| 训练侧诊断 | positive | zero |
|---|---:|---:|
| 正响应目标达成率，按全部正关系计数 | 65.19% | 65.05% |
| 正关系中跨视图最小间隔增量反为负的比例 | 26.91% | 27.17% |
| 两视图 LA 改善 / 受损的事件—类别数 | 135 / 25 | 135 / 25 |
| 原始评估视图上准确率改变的事件—类别数 | 0/160 | 0/160 |

达成率的单位是“事件—训练样本—竞争类别”的正响应关系：两个视图都达到原本希望增加的间隔，允许1e-6数值容差。它不是测试精度，不是独立验证集，也不是独立样本实验数。正关系反为负表示至少一个视图的间隔下降，不等同于分类出错。

第30轮两组筛选出的60条关系完全相同，基准 logits 最大差异约9.54e-6。此次目标样本上的输出变化向量余弦相似度为 **0.999827**，相对差异约1.86%；独立 C 的向量余弦相似度为0.998639。后续轮次的训练状态已发生分化，不能再当作严格固定状态的消融。

这说明正响应分支在数值上参与了训练，但没有在本次配置中产生清晰不同的学习行为。不能把65%的达成率单独写成正响应监督有效的证据，因为没有使用正增量监督的 zero 也能达到近似比例。

将 zero 也按其各事件真实正增量目标重新计分，平均正响应误差约0.00038068，positive 为0.00036879。存在小幅数值差异，但后续教师与状态不同，且测试差距仅0.015个百分点，尚不足以确立独立效果。

证据：`positive_zero_comparison.csv`、`events.csv`、`class_changes.csv`。

**5. 对原因的判断，应分清证据和推测**

已经确认的是：来源可用、目标非零、C 确实发生更新；当前目标允许牺牲正响应误差，两组实际输出变化高度接近。不能把问题简单归结为“B 没有更新”：positive 的迁移有效范数是同轮普通 B 更新的1.72—3.00倍，更新绝对大小不是零。

进一步在保存的 logits 上计算目标对 logits 的梯度，在每次 C=0 时，正响应项梯度范数约为 LA 的2.15%—2.69%，两者方向余弦约0.707—0.736。这提示正响应项尺度较弱，并与直接标签学习部分重合，符合两组行为接近的观测。

但这些是输出空间梯度，不是 C 参数空间梯度。分析包没有模型、donor 原始更新或计算图，无法复算模型 Jacobian，也不能断言 C 梯度恰好只有相同比例。现有证据也不能证明单独增加响应系数、步数或改优化器就能改善测试精度。

因此，更合适的工作解释是：**目前 C 主要表现为利用 donor 更新基底进行尾类标签校准，正响应目标提供的额外引导较弱；用一个固定权重直接相加，尚未可靠地把选中的正向帮助转化为额外分类能力。** 这是解释现有观测的判断，不是排除了所有替代原因的因果结论。

证据：`logit_gradients.csv`、`positive_zero_comparison.csv`、`events.csv`。

**6. 尾类存在收益，也仍有类别取舍**

positive 相对 A-only，在固定 Tail20 中9类最后20轮测试均值提高、6类降低、5类相同。例子如下：

| 类别 ID | positive − A-only，百分点 |
|---|---:|
| 81 | +0.85 |
| 95 | +0.70 |
| 97 | +0.70 |
| 91 | +0.55 |
| 93 | −1.00 |
| 86 | −0.30 |
| 99 | −0.30 |

135/160个事件—类别的训练 LA 改善，不能解释成135个类别准确率提升。原始训练评估视图的分类结果在这些迁移前后均未改变。另一方面，当前存在测试小幅收益，也不能因为训练侧分类结果没变就说完整训练完全无效。

训练侧类84在8次事件的两视图 LA 都受损，但其测试均值与 A-only 相同；类93的训练 LA 在6次事件受损，测试均值也低1.00。两类例子共同说明：应报告训练机制和测试结局，不能用训练损失变化替代测试准确率或证明两者的唯一因果关系。

证据：`tail_class_comparison.csv`、`class_changes.csv`。

**7. 当前能固定什么，不能固定什么**

可以继续保留的方法边界是：B 只使用目标尾部客户端的尾类反馈；来源来自目标组外且缺对应类别标签；保留每 donor 独立 C；推理仍使用一个共享模型。这些设计已正确运行，本次结果不要求取消 C。

暂不能固定的主张是：“加入这套正响应监督，相比同等 C 校准可靠地增强了尾类学习。”本次 positive 与 zero 的差别过小，且训练机制没有展示预期的响应误差改善。也不能把 zero 超过 A-only 的0.065个百分点全部归因于 C 或筛选，因为 zero 同时包含来源基底、额外尾类监督和基准间隔参考。

如果继续修改，应优先处理响应目标与 LA 在 C 优化中的尺度及取舍，使正响应能够影响最终更新。修改方案需要同时接受训练侧目标和预设测试指标的检验；不应根据本次测试曲线改选最好轮次或最好类别。现阶段没有依据要求重新扩大 donor 搜索、取消 C，或立即展开新的大规模实验组合。

由于用户本次要求是分析，本轮没有调整损失、超参数或实验设置。单种子结果不足以最终确认或否定0.015个百分点的稳定性；是否继续复现当前方案，还是先修正目标，应结合上述机制证据决定，不能把“尚未证实”写成统计上已经证明无效。

**8. 核验范围与成本记录**

共3694项数据一致性检查通过，包括训练完成状态、原始逐类精度与 Tail20 汇总、历史对照的划分/初始化/模型/调度/测试集哈希、迁移前评估一致性、来源资格/Top-3/权重、选中教师分数、逐样本目标构造、zero 置零、冻结竞争权重、LA 和响应损失复算、独立 C 索引及矩阵正则。

两组各计入57120次算法前向图像访问、3808次反向图像访问、4760次诊断前向和16次 C 更新。B 事件计时分别约195.6秒、189.0秒；全程约14.06小时、15.66小时。不同服务器负载或硬件会影响时间，不能从全程时长差异声称算法加速。通信字段是实现定义下的模拟计数，不是实际网络测量。

原包不含 `.pt`，无法独立从原始 donor 张量重建最终共享残差；也不能独立复算未选中 donor 的前向分数，其资格和排序只能通过记录核验。报告将这些限制与已验证内容区分开。

主要文件：`performance.csv`（结果比较）、`tail_class_comparison.csv`（逐尾类测试差异）、`events.csv`（8次迁移汇总）、`objective_trace.csv`（C 优化目标）、`positive_zero_comparison.csv`（两组行为差异）、`logit_gradients.csv`（输出空间分析）、`costs.csv`（成本）、`checks.csv` 和 `audit.json`（核验及来源）。
