# 检索范围与证据边界

日期：2026-09-28。主报告：`report.md`。

检索前确定的三个问题是：头到尾迁移的对象与身份保持；类别之间负迁移的控制与保证边界；适配缺标签 donor、共享 CLIP-LoRA、少量目标反馈的方法 B。

实际执行的独立视角：

1. 特征、分布统计和共享几何的迁移；核查 FSA、DC、GistNet、MetaSAug、FASA，并以2026年 DBG 作近期边界检查。
2. 语义污染、蒸馏偏差、结构分离和基础模型泛化；核查 Decoupling、RIDE、DiVE、BKD、LIFT 和 TCL。
3. 梯度冲突的优化保证；核查 GBG、MGDA、GEM、PCGrad、CAGrad。
4. 主线核查联邦适配条件与本地代码；读取 CAPT、FedAFA、FedLoGe，并对照 B 的筛选、重建、反馈及逐类结果。

主报告使用18篇文献。BKD 和 FedLoGe 虽已检索核验，但因与主报告论点重复而未纳入正式书目。以下边界在报告中保留：

- TCL：CVF 官方摘要与书目核实，全文访问失败；只采用摘要明确描述，未使用二手公式。
- DBG：作者 arXiv 全文与方法、结果表核实；会议接收状态只按作者声明，不当作另核正式会议录。
- DisVar：未取得可核查原始全文，未纳入具体机制证据。
- LEAP：核查元数据但全文未充分读取，未纳入核心机制证据。
- FedR2G：检索出现晚于本次调研日期的正式卷期日期，且不是回答当前问题所必需，未使用其结论。

复核重点：FSA 是 ECCV2020；FASA 是实例分割且主要为本类增强；DC 是 base/novel 标签不交的少样本评估；GBG 的共同下降主要针对类别组；GEM 等方法的经验一阶性质不能扩写为测试保证。

反向证据没有删去：DiVE、DBG 存在尾组改善而头组下降的设置；GBG 的直接 MOO 消融显著变差；本地类别81、86、95的即时训练 LA 与长期测试变化不一致。主报告据此没有认定 C 或梯度冲突是当前测试收益不足的唯一原因。

文献检索和文件分析均为只读研究。新增文件只在本目录；没有修改训练方法或启动新实验。
