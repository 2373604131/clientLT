# 方法 A：模型示意图重绘

figure-designer 绘制前设计；替代文字流程图，旧文件保留作比较。

- 图型：Solution Overview / 模型与系统架构。核心是图片、编码器、LoRA 参数、特征、预测与服务器；不再把算法段落装进矩形。
- 表达目的：读者首先看懂模型怎样处理图像，以及方法 A 在普通聚合之后改动什么参数。
- 范围：A 阶段。此前已经训练并聚合 B；本图中 B 固定不代表 B 全程冻结。
- 左：本地图片与类别文本分别经过 CLIP 两个编码器；主干冻结，LoRA A 训练、B 固定；特征经余弦相似度得到分类预测与 LA 损失。
- 中：客户端上传 A，服务器依原样本量权重聚合，产生普通提案。
- 右：普通提案在本地固定训练图片上得到预测；更新影响和五轮历史分别提供保持权重与目标；保持损失和分类损失反馈到 A，执行三步修正。
- 视觉语法：梯形是编码器，小矩形是 LoRA 因子，条带是特征，柱形是示意预测；雪花表示固定，火焰表示训练。图形符号承担主要表达。
- 辅助小图：用向量方向表示一阶更新影响，用五个示意间隔柱表示历史登记；均不冒充实验数据。
- 色彩：亮蓝 #1479E0、橙 #F28E2B、绿 #159B75，白底、浅色分区。冻结/训练另以形状和文字区分。
- 工具：TikZ 生成可编辑矢量 PDF/SVG；输入图片从本地 CIFAR-100 原始训练数组导出，仅用作输入示例。
- 文字：仅短标签与必要参数符号；推导、协议细节和解释移到独立图注。
- 质量控制：实际查看中英文 PNG，核对算法事实、箭头方向、图形遮挡、8pt 以上正文与矢量导出。最多三轮成图修复。
