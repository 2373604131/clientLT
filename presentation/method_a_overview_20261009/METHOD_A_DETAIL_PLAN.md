# 右侧方法 A 的局部重绘

## figure-designer 绘制前设计

本次只展开原概览图右侧的方法 A；保留原左侧训练与中间聚合图，不修改算法。输出独立的中英文方法细节图，便于先检查机制是否讲清楚，再决定整篇论文的版面组合。

原图问题：更新影响的向量小图没有说明筛选规则；ω 没有说明是保持损失的权重；历史柱没有解释如何得到目标；损失符号没有表示“预测未达目标”和“分类损失上升”这两个实际惩罚条件。

- 类型：Solution Overview。
- 范式：模型架构 + 两个机制放大图。下半部分保留图片输入、CLIP、LoRA A/B、特征与预测；上半部分展示目标和权重的构造。避免再次变为只有步骤框的流程图。
- 左上：同一客户端的同类图片在共同模型上产生间隔梯度；与各客户端更新做内积，展示两视图的正负响应；只保留两视图均为正的更新。正向影响的均值产生当前目标，集中程度决定保持权重。
- 右上：五轮已提交模型的示意间隔，取最低水平并在满足改善条件后登记；历史目标与当前目标取较大者。
- 下方：普通聚合 A 初始化候选模型；固定图片通过冻结 CLIP + 可训练 A / 固定 B；预测间隔低于目标的缺口产生带权保持损失。另一小图单独表达相对普通聚合的分类损失上升才受惩罚。损失梯度回到 A，三步、限制修正幅度。
- 关键标注：保持权重，而非客户端聚合权重；当前目标，而非当前预测；历史值不是偶然最佳值；只惩罚目标缺口；分类约束是软惩罚。
- 配色：蓝色模型与客户端更新，绿色有效目标与历史，橙色保持权重/缺口/修正，灰色被排除的更新。配合正负号、线型、雪花/火焰和标签，不仅靠颜色。
- 格式：TikZ 原生矢量；沿用实际 CIFAR 输入缩略图，所有符号、柱形、参数块和模型都是可编辑图元。
- 字号：源宽 18 cm，正文不小于 8.8 pt；推荐通栏。此为单独展开的右侧细节图，不能直接缩塞回原来约 8 cm 的区域。
- 成图后：实际查看中英文 PNG，检查目标/权重箭头与梯度回路，核查协议，测量文字边界；至多三轮布局修复。

图中的符号矩阵、柱高和缺口为机制示意，不声称实验效果。图注明确省略视图下标、尺度归一化、登记阈值和完整正则公式。
